# 카드 일러스트 만드는 법

사도 135명 × 카드 8장 = **1,080장**을 그립니다.
자리는 **시작 카드 넷 · 고유 카드 넷**입니다.

**고학년 스킬은 그리지 않습니다.** 인게임 고학년 스킬이고 그 아이콘이 곧 그 사도의 고학년 스킬 표라,
원작 아이콘(`icon_graduateskill_*`)을 그대로 씁니다. 육각 틀에 작게 들어가는 자리라
일러스트를 넣으면 잘려서 무엇인지 안 보입니다. 그려 넣어도 바뀌지 않습니다.

지금 597자리에는 원작에서 꺼낸 스킬 아이콘이 박혀 있습니다. 그건 **우리 것이 아닙니다.**
자리가 비어 보이지 않게 임시로 메워 둔 것이고, **고유 카드와 고학년 스킬까지 전부 다시 그립니다.**
그린 것이 들어오면 아이콘은 자동으로 물러납니다.

```
node tools/art-brief.js --todo          지금 몇 자리 남았나
node tools/art-brief.js 에르핀           그 사도에게 필요한 것 전부
node tools/art-brief.js 에르핀_s2        카드 한 장
node tools/art-brief.js 에르핀 --json    기계가 읽을 꼴
node tools/art-brief.js 에르핀 --short   인물 사전은 빼고 짧게
```

`art-brief` 한 줄이면 사도 정보 · 참고 그림 경로 · 카드 아홉 장의 글 · 낼 곳 · 붙일 말이
다 나옵니다. **자료를 여기저기서 긁어 오지 마세요.** 기획서가 바뀌면 이 도구만 따라옵니다.

---

## 1. 한 사도를 통째로

아홉 장을 한 자리에서 끝내세요. 참고 그림을 한 번만 물리면 되고, 같은 손과 같은 빛으로
아홉 장이 나옵니다. 사도를 건너뛰며 한 장씩 그리면 같은 사람이 카드마다 달라 보입니다.

## 2. 참고 그림 — 얼굴을 잃지 않으려면

`art-brief` 가 적어 주는 차례대로 넣습니다.

| 파일 | 무엇 |
|---|---|
| `assets/sd/<사도키>.png` | 252×252 SD 초상. **신원 참고로 이것을 먼저 넣습니다** — 얼굴·머리·눈빛이 한 장에 붙어 있습니다 |
| `assets/spine/standing/<사도키>/<영문>.png` | 1528×1024 스탠딩 아틀라스. 옷·장식·소품이 조각으로 다 들어 있습니다. **색과 장식은 여기서 봅니다** |
| `assets/heroicons/<영문>.png` | 도감 아이콘. 위와 같은 그림인 경우가 많습니다 |
| `assets/sd/minimi_<사도키>.png` | 미니미. 키와 몸 비율 |

아틀라스는 **조각이 흩어진 판**입니다. 그대로 베끼라는 뜻이 아니라 머리 장식·리본 색·
무기 모양 같은 것을 확인하라는 뜻입니다.

## 2-1. 그 사도가 어떤 사람인지 — 인물 사전

`art-brief` 가 참고 그림 다음에 **인물 사전**을 펼칩니다. 옷과 얼굴은 참고 그림에서 보고,
**무엇을 하는 사람인가**는 여기서 봅니다.

| 칸 | 무엇에 쓰나 |
|---|---|
| `who` | 어떤 사람인가 — 배경과 자리 |
| `설정` | 확정된 것 — 종족·성격·나이·관계·좋아하는 것 |
| `버릇과 성미` | **장면은 대개 여기서 나옵니다.** 에르핀의 「하루 열두 끼」가 곧 「친구 몰래 케이크」입니다 |
| `말버릇` | 표정과 몸짓의 결 |
| `감정` | 기본 표정이 무엇인가 |
| `상황별 표정` | **카드 타입마다 얼굴이 달라야 합니다.** 공격 카드와 회복 카드가 같은 얼굴이면 안 됩니다 |
| `하지 않는 것` | 그리면 안 되는 것 |

에르핀을 예로 들면 — 「200kg 벤치프레스를 300번」·「맨주먹으로 마법 보호막을 깼다」가
`정권파괴술`(방어·실드 전부 파괴) 그림을 그대로 설명합니다. 장면이 안 떠오르면 버릇을 읽으세요.

**주의 두 가지.**

- **옷은 인물 사전이 아니라 참고 그림에서 봅니다.** 사전은 글이라 색을 틀리게 만듭니다
- **이격 둘**(우이(기억) · 비비(신성))은 아직 사전에 없어 기본 사도 것을 빌려 옵니다.
  도구가 그렇다고 밝혀 줍니다 — 이격은 옷도 성미도 달라질 수 있으니 참고 그림을 먼저 믿으세요

인물 사전은 나무위키 트릭컬 리바이브 사도 문서를 읽고 요약·재구성한 것으로
**CC BY-NC-SA 2.0 KR** 을 따릅니다(저작자표시 · 비영리 · 동일조건변경허락). 원문이 아닙니다.
사전이 없으면 `npm run bible` 로 다시 만듭니다.

## 3. 카드 글 → 장면

카드 글은 숫자가 아니라 **동작**입니다. 숫자는 화면이 따로 적으니 그림에 넣지 마세요.

| 카드 | 글 | 그릴 장면 |
|---|---|---|
| `에르핀_s0` 마력탄 | 공격력 100% 피해 | 지팡이를 휘둘러 마력 구슬을 날린다. 한 방, 가볍게 |
| `에르핀_s2` 특대 마력탄 | 공격력 220% 피해 | 같은 동작인데 **더 크게**. 구슬이 몸통만 하고 반동으로 머리가 젖혀진다 |
| `에르핀_s3` 도끼도 튕기는 몸 | 방어력 200% 방어 | 머리로 날아든 도끼가 튕겨 나간다. 에르핀은 멀쩡하고 오히려 어리둥절. **왕관은 벗지 않는다**(저주로 못 벗는다) |
| `네르_u1` 기도입니다, 잠 아니고요 | 방어력 400% 방어, 다음 턴 AP +1 | 손을 모으고 눈을 반쯤 감았다. 정말 자는 건지 기도인지 모르게 |
| `티그_u0` 소닉 블레이드 | 순간 전진해 베고 복귀 | **쌍검**이 잔상을 남기고 이미 지나간 뒤. 티그는 착지 중 |

세 가지를 맞춥니다.

- **타입** — 공격이면 때리고, 방어/방어면 막고, 회복이면 살리고, 스킬/강화면 기운을 두릅니다
- **세기** — 100%와 220%는 같은 그림이면 안 됩니다. 크기·반동·잔상으로 갈라 주세요
- **그 사도의 것** — 소개 글과 패시브·키워드를 읽으세요. 에르핀은 먹보 여왕이라
  케이크 카드가 있고, 네르는 늘 졸려 있고, 티그는 **검 두 자루**를 씁니다

## 4. 언제나 붙이는 말

`art-brief` 가 아래를 그대로 찍어 줍니다. 그림마다 똑같이 씁니다.

```
스타일  Polished hand-drawn 2D anime game card illustration, bold clean warm-brown
        contours, rich cel shading, softly painted simplified background,
        luminous cream highlights. Chibi proportions with a large round head —
        never realistic adult anatomy. Whimsical storybook collectible-card look.
구도    Portrait 2:3, single character only, face unobscured and readable at
        thumbnail size, quieter lower third for later UI overlay, edge-to-edge art.
금지    No text, no numbers, no card frame, no UI, no watermark, no extra characters.
        Do not change the reference's hair colour, eye colour, costume or props.
크기    1024×1536 PNG
```

**그림은 카드를 꽉 채웁니다.** 코스트·이름·타입이 **위에**, 효과 글이 **아래에** 얹히고
그 자리에는 어둠이 깔립니다. 그러니 **위 15%와 아래 25%에 얼굴이나 무기 끝을 두지 마세요.**
가운데를 비우고 주변을 채우면 카드에서 아무것도 안 보입니다.

원작 스킬 아이콘으로 메운 자리만 가운데에 작게 뜹니다. 그린 것이 들어오면 꽉 차게 바뀝니다.

**글자를 그리지 마세요.** 코스트·이름·타입은 화면이 그립니다. 그림에 글자가 들어가면
카드 위에 글자가 두 번 찍힙니다.

## 6. 내는 법

```
assets/cardart/<사도키>/<카드id>.png
```

카드 id 는 `art-brief` 가 적어 주는 그대로입니다.

```
assets/cardart/에르핀/에르핀_s0.png     시작 카드 첫 장
assets/cardart/에르핀/에르핀_u0.png     고유 첫 장
assets/cardart/에르핀/에르핀_u3.png     고유 넷째 장
```

사도키에 괄호는 밑줄입니다 — `에르핀(왕도)` → `에르핀_왕도`.
그래서 이격의 시작 카드는 `에르핀_왕도/에르핀_왕도_s0.png` 가 됩니다.

넣은 뒤 두 줄:

```
npm run shrink     # 1024×1536 PNG → 512×768 WebP (장당 2.7MB → 144KB)
npm run cardart    # assets/cardart/ 를 훑어 js/data/cardart.js 로
```

**줄이는 걸 건너뛰지 마세요.** 카드는 화면에서 **152px** 로 뜹니다. 원본 그대로 두면
1,215장에 **3.1GB** 가 되고, 줄이면 **0.2GB** 입니다. 같은 크기로 봐서는 구별이 안 됩니다.

원본 `.png` 는 지우지 않습니다 — 나중에 크기를 다시 잡거나 다른 곳에 쓸 때 필요합니다.
`build-cardart` 가 `.webp` 를 먼저 보고, 없으면 `.png` 를 씁니다.

그린 것이 원작 아이콘을 **이깁니다**. 다시 돌리면 바뀐 만큼 셈이 올라갑니다.

```
카드 자리 1215개 → js/data/cardart.js
  우리가 그린 것 0
  원작 아이콘으로 메운 것 593 — 그린 것이 생기면 물러난다
  아직 아무것도 없는 것 — 그 사도의 SD 초상이 선다
```

> **2026-10-01 — 에르핀 카드 그림(AI 로 만든 8장)을 뺐다.** 다른 사도와 똑같이 원작 스킬 아이콘 · SD 초상으로 간다(사용자 결정).
> 그림은 지우지 않고 `.omc/removed-cardart/에르핀/`(저장소 밖)으로 옮겨 두었다.

## 7. 내기 전에 스스로 보기

한 장마다 이 여섯 줄을 읽고 넘기세요. 다시 그리는 편이 고치는 것보다 쌉니다.

1. **카드 글과 같은 일을 하고 있나** — 방어 카드인데 때리고 있지 않은가
2. **그 사도가 맞나** — 머리색·눈색·옷·소품이 참고 그림과 같은가
3. **무기 수가 맞나** — 티그는 쌍검이다. 검 하나면 틀린 그림이다
4. **얼굴이 보이나** — 썸네일 124px 로 줄여도 누군지 알아보겠는가
5. **글자가 없나** — 숫자·이름·테두리·UI 가 들어가지 않았는가
6. **아래 세 칸이 비었나** — 거기에 효과 글이 깔린다

도감에서 실제로 어떻게 보이는지 바로 볼 수 있습니다.

```
npm run serve     # http://127.0.0.1:8765
                  # 사도 도감 → 그 사도 → 왼쪽 갈피 '카드'
```

### 이미 나온 것 — 에르핀 아홉 장

첫 사도가 나왔습니다. 신원이 아홉 장 내내 흔들리지 않고, 배경도 요정 왕국으로 한결같습니다.
`정권파괴술`(방어·실드 전부 파괴)은 주먹이 푸른 결정을 깨뜨리는 그림이라 카드 글과 정확히 맞고,
`친구 몰래 케이크`는 나무 뿌리 뒤에서 몰래 먹는 눈빛까지 맞았습니다.

한 장만 어긋났습니다. **`에르핀_s3`(당시 이름 「왕관 가드」)는 방어 카드**(방어력 200% 방어)인데,
그림은 왕관을 두 손에 들고 서 있을 뿐 **막는 장면이 아닙니다.** (게다가 에르핀은 저주받은 왕관을 벗지 못한다 —
그래서 카드가 「도끼도 튕기는 몸」으로 바뀌었고, 그림도 다시 그려야 한다.) 빛 방패든 버티는 자세든,
방어가 눈에 보여야 합니다. 검사 목록 ①이 잡는 자리입니다.

### 흔한 실수

먼저 뽑아 본 석 장 가운데 티그 것이 그랬습니다. 프롬프트에
`One clearly constructed sword in one hand` 라고 적혀 있었는데, 티그의 시작 카드는
**쌍검 베기 · 쌍검 십자베기** 입니다. 그림은 잘 나왔지만 카드와 다른 사람이 됐습니다.

**프롬프트를 쓰기 전에 그 사도의 카드 아홉 장을 먼저 읽으세요.** `art-brief` 가
아홉 장을 한 번에 보여 주는 이유가 이것입니다.

## 9. 왜 원작 아이콘을 안 쓰나

`assets/skillicons` 는 원작에서 꺼낸 그림입니다. 자리를 메우는 데는 쓸 수 있지만
**우리가 만든 것이 아닙니다.** 이 프로젝트는 사도 데스크와 같은 원칙을 씁니다 —
가져다 쓴 것과 우리가 만든 것을 섞지 않고, 우리 것으로 갈아 끼웁니다.

`assets/` 는 통째로 `.gitignore` 라 저장소에도 안 들어갑니다. 그린 그림도 같은 곳에
들어가니 함께 올라가지 않습니다 — 올리는 방법은 따로 정합니다.
