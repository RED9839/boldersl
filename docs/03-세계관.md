# 세계관 — 지어내지 않는다

트릭컬에는 이미 정리된 세계 규칙이 있다. 이 게임이 그걸 어기면 팬게임이 아니라 그냥 다른 게임이다.

출처는 [사도 데스크 `docs/08-세계관-규칙.md`](https://github.com/RED9839/sado-desk) — 나무위키
`트릭컬 리바이브/설정`과 종족·지명 문서를 그쪽에서 추려 둔 표다. 거기에 기계 검사기까지 있어서
그대로 가져왔다(`tools/world-check.js`).

## 어기면 안 되는 것

| | 규칙 | 이 게임에서 |
|---|---|---|
| 1 | **죽음이 없다.** 죽을 자리는 '주말농장'(바다 쪽은 '주말어장') | 쓰러진 사도는 죽지 않는다. **주말농장에 간다** |
| 2 | **지성체는 전부 여성** | 남성 지칭을 쓰지 않는다 (엘프만 지구에서 산타를 겪어 남성을 안다) |
| 3 | 손가락은 넷, 키는 1m 안팎. 교주만 크고 손가락이 다섯 | 교주는 카드를 내는 사람이지 싸우는 사람이 아니다 |
| 4 | **늘 봄에 가까운 기후. 눈이 내리지 않는다** | 층 이름에 겨울·눈을 쓰지 않는다 |
| 5 | 지구·인터넷·지구 지명은 모른다 (엘프와 교주는 예외) | 엘레나·아멜리아만 지구 낱말을 쓴다 |
| 6 | 화폐는 골드·엘리프, 그리고 원 | 달러·엔을 쓰지 않는다 |
| 7 | 엘리아스 바깥(안개·황무지·바다)은 아무나 못 드나든다 | 층은 전부 엘리아스 안이다 |
| 8 | 세계수를 모시는 쪽은 요정·마녀·정령. 엘프·유령은 아니다 | — |

스포일러 금지도 그대로 따른다 — 세계수가 이미 죽었다는 것, 영원살이의 정체,
다른 차원(R41), 일곱 그루와 진명. **사도가 모르는 것은 이 게임에도 안 나온다.**
예외: **겨우살이**는 나온다(2026-10, 사용자) — 기적(신 번뜩임)을 내려 주는 이벤트의 주인공. 정체 · 세계수의 죽음은 말하지 않는다.

## 지명 — 층은 실제 지도에서 나온다

| 지역 | 종족 | 어디 |
|---|---|---|
| **에르피엔** | 요정 | 중앙, 세계수 주변 |
| **벨리티엔** | 마녀 | 지하, 세계수 뿌리 |
| **모나티엄** | 엘프 | 동부 |
| **수인 부락**(털 부락) | 수인 | 남동쪽 |
| **정령산** | 정령 | 남부, 가장 높은 산 |
| **유령 늪** | 유령 | 서부 (정식 명칭이 없는 유일한 지역) |
| **불길과 물길의 터** | 용족 | 남부 지하 |

지금 세 층은 **에르피엔 → 모나티엄 → 벨리티엔** 이다.
요정 왕국에서 시작해 엘프 도시를 지나 세계수 뿌리까지 내려간다.

## 적 — 실제 몬스터에서 나온다

추출한 몬스터 아이콘 410장에 **231종**의 진짜 이름이 있다. 지어낸 "굴러다니는 무언가"를 버리고
이걸 쓴다.

가장 큰 발견은 **누루링 시리즈**다(살아 움직이는 세계수 수액). 요정·엘프·수인·유령·정령·마녀·용족·미스틱 **여덟 종족 전부**에
대해 탱커·전사·마법사·서포터 네 역할씩 있다 — 종족 땅마다 그 영향을 받아 모습이 다르다. 세계관의 종족 체계와 그대로 맞물린다.
아이콘 파일은 `icon_<종족>curseddoll<역할>` 이라 처음엔 「저주 인형」 으로 읽었지만, 그림은 젤리이고 스파인은 `nururing*` 의 종족 스킨이다.
진짜 인형(`curseddoll`)은 원작 이름도 「누루링」 — 마녀가 누루링을 본떠 만들어 팔다 버린 인형이라 마녀 땅의 것이다.

적은 **그 땅에 사는 것만** 나온다 — 사는 곳은 도감의 교주의 기록이 말한다(「요정 왕국 주민」 · 「엘프들의 비행형 드론」 ·
「마녀들의 모자를 집 삼아」 …). 근거 표와 뺀 것은 [docs/11-적.md](11-적.md).

그리고 **적도 성격을 가진다.** 파일 이름이 `icon_<이름><성격>.png` 꼴이고 성격은
`naive / mad / cool / gloomy / jolly` — 순수·광기·냉정·우울·활발이다. 한 몬스터마다 다섯 벌씩 있다.
그래서 이 게임에서도 적이 성격을 갖는다.

## 검사

```
npm run world     # 카드 이름·설명·층 이름·사도 소개를 세계 규칙에 대고 훑는다
```

걸린 줄이 곧 오류는 아니다 — 예외가 많은 규칙이라 사람이 한 번 봐야 한다.
`--list` 로 규칙만 볼 수 있다.
