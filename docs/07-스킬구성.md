# 스킬 구성 — 사도 한 명을 다시 쓰는 법

사도마다 **패시브 · 키워드 · 고유 카드 4장(신탁 5개씩) · 고학년 스킬**를 나무위키를 읽고 다시 쓴다.
목표는 둘이다.

1. **그 사도답다** — 원작 스킬과 설정에서 나온 것이 카드와 패시브에 보인다.
2. **전투에서 실제로 돈다** — 여기 적힌 말로만 쓴다. 게임은 이 말들만 읽는다.
   글로만 있고 아무 일도 안 하는 패시브가 가장 나쁘다(전에 135명 전부가 그랬다).

쓰고 나면 `node tools/check-hero.js 파일.md` 가 **✓** 여야 한다.

## 2. 어디서 무엇을 가져오나

| 원작 | 여기서 |
|---|---|
| 저학년 스킬 | **시그니처**(첫 고유 카드) |
| 고학년 스킬 | **고학년 스킬** |
| 강화 평타 · 어사이드 · 애착 아티팩트 | **패시브**와 **키워드** |
| 역할(평가에 나오는 운용법) | 카드 네 장의 짜임 — 탱커는 막고, 서포터는 돕고, 딜러는 친다 |
| 설정(좋아하는 것·버릇·관계·사복) | 나머지 고유 카드, 신탁 이름, 카드 끝 한 줄 설명 |

**원작을 덱빌딩으로 옮긴다** — 어사이드·강화 평타는 실시간 전투 효과다. 그대로가 아니라 이렇게 바꾼다:
N초마다·쿨타임 → 카드 N장마다·턴마다 · 확률로 → N번째마다 · SP 회복 → AP·게이지 · 큰 % → 아래 수치 표 ·
전열/후열만 → 아군 전원. **「모든 아군 피해량 +N%」 처럼 늘 켜진 % 증가뿐인 원작 효과는 그대로 옮기지 않는다** —
조건(처치하면·맞으면·카드 N장마다·「X」가 있으면)이나 키워드와 엮어 전투에서 보이게 한다. 검사기가 막는다.

**엘다인** — 원작에서 엘다인은 스킬 체계가 아니라 **등급**이다(세계수의 힘을 받아 각성, 기본 스펙이 높고 얻기 어렵다).
그래서 여기서도 **고유 카드 체급이 한 단계 위**다: 코스트 값어치 평균 1.1배 이상(보통 사도는 0.85배 안팎), 한 장 상한 1.75배.
엘다인 패시브(두 번째 패시브)도 다른 패시브와 같은 기준 — 늘 켜진 % 가 아니라 하는 일이 보이게.

**패시브가 개성의 중심이다.** "공격 카드 세 장마다 간식 +1"(에르핀 — 강화 평타로 케이크를 꺼내 먹는다),
"아군이 맞으면 HP 최저 아군에게 방어"(네르 — 여왕 걱정)처럼, 읽으면 그 사람이 떠올라야 한다.
그냥 "주는 피해 +10%" 같은 것만 있으면 누구 것인지 모른다.

## 3. 모양

```
### 이름 (성격 · 종족 · 위치 역할 · 태생 N성[ · 엘다인])      ← 머리는 기획서와 한 글자도 다르지 않게
설명 한 줄                                                    ← 그대로 두거나 다듬는다
**스탯** …                                                    ← 그대로. 절대 바꾸지 않는다
**패시브** 이름: 규칙 · 이름2: 규칙2
**키워드 「X」** 설명 한 문장. 규칙 문장들.
**원작** 무엇을 어디로 가져왔는지 한 줄 (게임은 안 읽는다 — 근거를 남기는 줄)

**시작 카드 4장** (역할 구성)                                  ← 이름만 다듬을 수 있다. 효과·코스트는 그대로
- **이름**(1·공격) 공격력 100% 피해
…

**고유 카드 4장**
- **이름** (코스트·타입, 시그니처) 효과 — 끝에 한 줄 설명(선택)
    - ① 강화 *이름*: 바뀐 뒤 **전문**
    - ② 경량 *이름*: 바뀐 뒤 **전문**
    - ③ 연계 *이름*: …
    - ④ 변형 *이름*: …
    - ⑤ 각성 *이름*: …
- (나머지 세 장, 시그니처 표시 없음)

**고학년 스킬 (덱 밖 · 비용 N%)** **이름** — 효과
```

- 신탁 글은 **바뀐 뒤 카드의 전문**이다. 신탁을 고르면 카드 글과 효과가 통째로 갈린다.
  "② 경량: 보존" 이라고만 쓰면 그 카드는 **보존 말고 아무 일도 안 한다**.
- 코스트를 바꾸는 신탁은 글 앞에 `코스트 0.` `코스트 1.` 처럼 적는다.
- 끝의 ` — 설명` 은 사람이 읽는 말이라 게임이 떼고 읽는다. 효과를 그 뒤에 쓰지 않는다.
- 엘다인은 패시브를 둘 쓴다: `이름: … · 엘다인 「이름」: …`. 엘다인이 아니어도 둘까지 된다.

## 4. 패시브 문법

```
**패시브** 이름: [언제] [조건] 효과, 효과 [(전투당 N회) — 위급할 때만]
```

**언제** (정확히 이 말로)

| 말 | 뜻 |
|---|---|
| `전투 시작 시` | 전투를 열 때 한 번 |
| `턴 시작 시` · `턴 종료 시` | 내 턴 처음 · 끝(적이 움직이기 전) |
| `카드를 낼 때마다` | **이 사도의** 카드 |
| `공격 카드를 낼 때마다` · `스킬 카드를…` · `강화 카드를…` | 이 사도의 그 타입 카드. 타입은 셋뿐이다(2026-10) — 옛 방어 · 회복 카드는 스킬이라 `스킬 카드` 에 든다. 막는 · 채우는 카드만 세려면 효과 말(`방어나 실드를 얻으면` 따위)을 쓴다 |
| `시그니처 카드를 내면` | 이 사도의 시그니처(신탁으로 바뀐 것도) |
| `에르핀의 공격 카드를 3장 낼 때마다` · `에르핀의 카드를 4장 낼 때마다` | **그 사도가 낸 카드만** N장마다 한 번 — 이름을 꼭 적는다(장비는 `자신의 …` = 낀 사도). 이름 없는 옛 글도 같은 뜻으로 읽지만 파티 전체로 읽혀서 바꿨다(2026-10) |
| `에르핀의 1코 이상 카드를 3장 낼 때마다` | 적힌 코스트가 N 이상인 카드만 센다 — 0코 순환 카드가 장수 패시브를 공짜로 돌리지 않게(바리에). **AP · 드로우를 주는 장수 패시브는 반드시**(쓴 AP 보다 돌려받는 AP 가 늘 적다) |
| `실비아의 1코 이상 스킬 카드를 한 턴에 2장 낼 때마다` | 그 턴 안에서만 센다 — 턴이 바뀌면 0 부터(실비아). 안 적으면 전투 내내 이어 센다. 뒤에 조건(「X」가 N개 이상이면)이 붙으면 장수는 늘 세고 N장째에 조건을 본다 |
| `파티가 공격 카드를 4장 낼 때마다` | 누가 냈든 파티 전체로 센다 |
| `아군이 카드를 낼 때마다` · `아군이 공격 카드를 낼 때마다` | 파티 누구든 |
| `파티가 이번 턴 카드를 3장째 낼 때` | 파티가 그 턴 세 번째 카드를 낼 때 — 턴에 한 번(옛 글 `한 턴에 카드를 3장째 낼 때`) |
| `방어나 실드를 얻으면` · `실드를 얻으면` · `아군이 방어나 실드를 얻으면` | 이 사도(아군이면 누구든)에게 방어 · 실드가 붙을 때 |
| `적이 즉시 행동하면` | 적이 카드 장수에 당겨져 즉시 움직였을 때(적마다 턴에 한 번) |
| `적을 처치하면` | 이 사도의 카드(또는 패시브)로 쓰러뜨렸을 때 |
| `적이 쓰러지면` | 누가 쓰러뜨렸든 |
| `피해를 받으면` · `아군이 피해를 받으면` | 체력이 깎였을 때(방어가 다 막으면 아님) |
| `HP가 50% 이하가 되면` | 이 사도가 처음 그 아래로 내려갈 때 — 전투당 1회 |
| `아군이 쓰러지면` | |
| `고학년 스킬을 쓰면` | 이 사도가 고학년 스킬을 쓰면 |
| `연계가 터지면` | 이 사도가 낀 연계 |
| `적에게 디버프를 걸면` | 이 사도가 적에게 취약·약화·기절 따위를 걸 때 — **일 하나(카드 한 장 · 패시브 한 번)에 한 번**. 적 전체에 걸어도 한 번 |
| `회복량이 최대 HP를 초과하면` | 이 사도의 회복이 대상의 최대 HP 를 넘을 때 — 회복 효과 하나 · 대상 하나에 한 번. 남이 채운 것은 안 센다(나이아, docs/15) |
| `「X」가 5개가 되면` | 자기 키워드가 5에 닿는 순간 |
| `항상` | 늘 걸려 있는 능력치 증감(아래) — 15% 까지 |

**조건** (언제 뒤에, 선택)
`「X」가 있으면` · `「X」가 3개 이상이면` · `HP가 50% 이하이면` · `HP가 70% 이상이면` · `적이 3명 이상이면` · `적이 1명뿐이면` · `혼자 남으면` ·
`파티가 이번 턴 카드를 3장 이상 냈으면`(`… 2장 이하로 냈으면`) · `이번 턴 에르핀의 카드를 내지 않았으면`(장비는 `자신의`) · `AP가 남았으면` ·
`고학년 게이지가 100% 이상이면` · `실드가 있으면`(`방어나 실드가 있으면`) · `적이 즉시 행동했으면` · `첫 턴이면` ·
`지난 턴에 피해를 받았으면` · `지난 턴에 아군이 피해를 받았으면` · `지난 턴 적을 처치했으면`(「지난 턴」 = 내 지난 턴부터 적의 차례 끝까지 — 턴 시작 시와 엮는다)

**장수는 누구 것인가** — 글에 밝힌다(2026-10, 사용자). `에르핀의 …` 는 그 사도 것만, `파티가 …` 는 누가 냈든. 사도 정보 창의 칩도 「에르핀 공격 1/3」 · 「파티 2장」 으로 갈린다.
`낼 때마다` · `파티가` 에는 밑줄 풀이가 붙는다(tools/build-keywords.js).

**횟수** — `(턴당 N회)` 는 **쓰지 않는다**(2026-10, 사용자 「패시브에 턴당 최대 조건 없애라」 · 검사기가 막는다). 대신 언제 · 값으로 막는다.
- `(전투당 1회)` 는 위급할 때 한 번만 — `HP가 N% 이하가 되면`(안 적어도 전투당 1회) · 처음 맞으면 · 아군이 쓰러지면. 전투를 여는 한 번은 `턴 시작 시 첫 턴이면`.
- **AP · 드로우**는 언제 자체가 한 턴에 몇 번 못 도는 것에만: 턴 시작 시 · 턴 종료 시 · 전투 시작 시 · 파티가 이번 턴 N장째 · 「X」가 N개가 되면 ·
  이름의 1코 이상 카드를 N장(N ≥ 2) · HP N% 이하 · 고학년 스킬. 드로우는 적을 처치하면도 된다(적 수만큼). 맞을 때 · 처치할 때 주던 AP 는 `턴 시작 시 지난 턴에 …`.
- 맞을 때마다 · 카드마다 도는 것은 **작게**(키워드 +1 · 작은 회복 · 작은 방어). 큰 반격은 `턴 시작 시 지난 턴에 피해를 받았으면`.
- 규칙은 **제 효과로 다시 돌지 않는다**(「디버프를 걸면 … 약화」 · 「방어를 얻으면 … 방어」 — js/passive.js). 패시브가 패시브를 부르는 깊이도 넷까지.
- tools/check-passive.js 의 폭주 검사 — 사도마다 거센 턴(AP +3, 손에 든 것을 다 낸다)을 돌려 패시브가 한 턴에 AP +2 · 드로우 3장 · 공격력 15배 피해를 넘지 않는지 본다.

**보기**
```
**패시브** 왕의 품격: 턴 시작 시 지난 턴 적을 처치했으면 AP +1 · 엘다인 「축복의 여왕」: 전투 시작 시 이번 전투 동안 아군 전원 공격력 +5%
**패시브** 와구와구: 에르핀의 공격 카드를 3장 낼 때마다 「간식」 +1
**패시브** 카리스마 발산: 파티가 이번 턴 카드를 3장째 낼 때 아군 전원 사기 1
**패시브** 결벽증: 턴 종료 시 자신 디버프 1개 해제
**패시브** 도파민 중독: 피해를 받으면 「겁」 +1 · 겁쟁이 사냥꾼: 항상 자신 치명 확률 +5%
```

## 5. 효과 — 카드·패시브·키워드·고학년 스킬이 같은 말을 쓴다

**피해**
- `적 1명에게 공격력 200% 피해` (고르는 적) · `적 전체에 공격력 80% 피해` · `무작위 적 공격력 60% 피해`
- `무작위 적 4회 × 공격력 50% 피해` · `적 1명에게 3회 × 공격력 60% 피해`
- `적 1명의 방어·실드 전부 파괴 후 공격력 200% 피해` · `적 전체의 방어·실드 전부 파괴`
- X 코스트: 코스트 자리에 `X`, 글에 `무작위 적에게 (AP+「X」)회 × 공격력 70% 피해` — 남은 AP 전부를 쓴다

**방어·실드·회복** (대상 말이 없으면 자신)
- `방어력 250% 방어` · `아군 1명 방어력 200% 방어` · `아군 전원 방어력 150% 방어` · `HP 최저 아군 방어력 300% 방어`
- `방어력 300% 실드` (실드는 턴이 지나도 남는다, 방어는 다음 내 턴에 사라진다)
- `아군 1명 HP 회복(회복력 70%)` · `아군 전원 HP 회복(회복력 40%)` · `HP 최저 아군 HP 회복(회복력 90%)` · `자신 HP 회복(회복력 60%)`

**자원** `드로우 2` · `AP +1` · `게이지 +20%` · `손패 2장 버리고 드로우 3` · `손패 전부 버리고 드로우 5`

**상태** — 숫자는 **겹**(카제나, docs/16 · 수치는 js/rules.js `STATUS_V`). 효과는 정해져 있고 한 번 돌 때마다 1 준다(카드 한 장 · 적의 수 하나가 한 번). 턴으로는 안 준다. 다시 걸면 더해진다.
- `적 1명 취약 2` (받는 피해 +50%) · `적 전체 약화 1` (주는 피해 -25%) · `자신 사기 1` (주는 피해 +20%) · `아군 전원 불굴 2` (받는 피해 -20%)
- `적 1명 손상 1` (얻는 방어 · 실드 -50%) · `결의 2` (턴 끝에 방어력 50% 실드) · `결정화 3` (턴 끝에 겹마다 방어력 20% 실드, 줄지 않는다)
- `적 1명 고통 3` (턴 끝에 겹만큼 고정 피해, 그 뒤 절반) · `아군 1명 반격 2` (적에게 맞으면 방어력 150% 로 되친다) · `적 1명 표식 2` (공격 카드에 맞으면 덤 타격 100% · 강인도 1칸)
- 대상 말이 없으면 버프(사기 · 불굴 · 결의 · 결정화 · 반격)는 자신, 디버프(취약 · 약화 · 고통 · 손상 · 표식)는 고른 적. 옛 글 `취약 2턴` 은 `취약 2` 로 읽는다
- `적 1명 기절` (다음 수를 못 한다) · `적 1명 침묵 2턴` (공격 아닌 수를 못 한다)
- `자신 도발 1턴` (적이 이 사도만 친다) · `자신 무적` (다음 내 턴까지 피해를 안 받는다)
- `디버프 1개 해제` · `아군 전원 디버프 1개 해제` · `HP 5 소모` · `최대 HP 10% 소모`

**능력치 증감** — **모두 상태로 쓴다**(docs/16 §6 베껴 쓰는 줄). % 증감(`주는 피해 +N%` · `공격력 +N%` …)은 새 글에 쓰지 않는다 — `판 내내`(강화 카드)만 예외.
- 주는 피해 → `사기 N` · 받는 피해 감소 → `불굴 N` · 받는 피해 증가 → `취약 N` · 주는 피해 감소 → `약화 N`
- 공격력 → `열의 N`(+20%) · 방어력 → `강건 N`(+20%) · 치명 확률 → `집중 N`(+20%p) · 회복력 → `온정 N`(+20%) — 그 능력치를 쓰는 카드 한 장마다 1 준다
- 벌칙으로 스스로 거는 것도 된다: `자신 취약 1` · `자신 약화 1`
- tools/convert-mods.js 가 옛 글을 바꿨다. 남은 % 는 `판 내내` · `항상` · `1개당`(키워드 세기) · 장비 · 교주의 작은 증감 몇 곳뿐
- `판 내내 자신 공격력 +10%` · `판 내내 아군 전원 주는 피해 +5% · 받는 피해 -5%` — **강화 카드에만**(docs/15 §7). 판이 끝날 때까지 다음 전투마다 다시 걸린다(run.boons).
  자신 20% · 아군 전원 10% 까지, 제 편에 좋은 것만, 카드 하나에 둘까지(check-hero). 다른 카드 · 패시브 · 고학년 · 축복에는 쓰지 않는다

**강화 카드** — 종류(머리의 `(1·강화)`)가 강화인 고유 카드, 또는 신탁 글이 `강화 카드.` 로 시작하는 것(그 신탁을 고르면 카드가 강화 카드가 된다).
사도마다 하나까지. 덱에 한 장만 · 복제 불가 · 내면 이 전투에서 사라지고 판의 덱에서도 빠진다 — 그래서 `소멸` 을 따로 적지 않는다.
강화 카드는 기본과 신탁 다섯 모두 `판 내내 …` 증감을 하나 든다.

**키워드** — 자기 키워드만. 낫표를 두른다.
- `「간식」 +1` · `「간식」 2 소모` · `「간식」 전부 소모`
- `「간식」이 있으면 …` — **이 말 뒤의 효과만** 있을 때 돈다. 앞은 늘 돈다. 카드 끝에 둔다.
- 적에게 거는 표식은 `적 1명에게 「늑대 표식」 +2` · `적 전체에 「늑대 표식」 +1`
- 아군에게 씌우는 것은 `아군 1명에게 「계시」 +2` · `아군 전원 「계시」 +1` · `자신에게 「계시」 +1`
- 표식 소모: 카드에서는 `적 1명의 「늑대 표식」 전부 소모`(고른 적에게서) · 키워드 규칙 `「X」가 N개가 되면:` 안에서는 그 표식을 든 사람에게서 빠진다

**태그** `보존`(턴이 끝나도 손에 남는다) · `소멸`(내면 이 전투에서 사라진다) · `개전`(첫 손패에 든다)
— 효과 글 맨 앞이나 맨 끝에 한 낱말로. 머리의 `(1·스킬, 소멸)` 에 적어도 된다(신탁은 글에 다시 적는다).

**강인도 · 격파** (카제나 — 수치는 js/rules.js `TOUGH` · `STATUS_V`, 엔진은 js/combat.js `toughHit`)
- 적마다 강인도 칸(보통 3 · 엘리트 4 · 보스 5, enemies.js `tough` 로 바꾼다)과 약점 성격(상성에서 — 그 성격을 이기는 성격, `weak` 로 바꾼다)이 있다.
  공격 카드(고학년 스킬 포함) 한 장이 적을 처음 칠 때 1칸, 약점이면 2칸. 여러 번 쳐도 한 장에 한 번. 패시브 · 키워드의 피해는 안 깎는다.
- 0칸이면 **격파** — 파티 AP +1 · 그 적 즉시 행동 1장 늦춤. 격파만으로 받는 피해는 늘지 않는다(카제나 — 덤은 잔불 · 잔광 · 파괴에서만). 다음 내 턴 시작에 다 찬다(덜 깎인 칸은 남는다). 보스는 판이 바뀌면 다 찬다.
- `적 1명에게 강인도 피해 2` — 약점과 상관없이 2칸
- `분쇄` — 이 카드는 방어 · 실드가 남은 적에게 피해 +20%
- `잔불` — 이 카드는 격파된 적에게 피해 +30%
- `잔광` — 이 카드는 강인도를 1칸 더 깎고, 격파된 적에게 피해 +50%
- `약점` — 이 카드는 성격과 상관없이 약점 공격(피해 +10% · 강인도 1칸 더)
- `파괴: AP +1, 드로우 1` — 고른 적이 격파됐을 때만 뒤가 돈다(이 카드의 앞선 타격으로 격파시켰어도). `「X」가 있으면` 처럼 **카드 끝에** 둔다
- 태그 넷(분쇄 · 잔불 · 잔광 · 약점)은 `보존` 처럼 글 맨 앞에 한 낱말로 — `분쇄. 적 1명에게 공격력 150% 피해`. 낫표를 두르면 사도 키워드로 읽는다(이프리트의 「잔불」)
- 적을 쓰러뜨리면 파티 AP +1(엔진 규칙 — 카드에 적지 않는다)

**카제나 카드 키워드** (엔진은 js/combat.js — handAuto · playCard · draw · endTurn. 자세히는 docs/16)
- `연계.` — 손에 있을 때 **다른 사도**의 카드를 내면 비용 없이 저절로 나간다(교주 카드는 안 깨운다)
- `천상.` — 손에 있을 때 비용 2 이상인 카드를 내면 저절로 나간다
  저절로 나간 카드도 다른 연계 · 천상을 깨울 수 있다. 한 사슬은 세 겹(AUTO_DEPTH)까지, 같은 카드는 한 번. 대상은 깨운 카드의 대상(없으면 맨 앞 적)
- `신속.` — 내도 적의 즉시 행동 셈이 늘지 않는다
- `증발.` — 턴이 끝날 때 손에 있으면 사라진다(보존보다 앞선다)
- `유일.` — 덱에 한 장만(옛 교주 글 「덱에 1장만.」 · 사도 강화 카드와 같은 규칙 — rules.js `isOnly`)
- `연속: …` — 이번 턴 바로 앞에 낸 카드가 같은 속성(사도 성격)이면 뒤가 돈다. `파괴:` 처럼 카드 끝에
- `감응: …` — 뽑힐 때 뒤가 돈다(낼 때는 안 돈다). 카드 끝에
- `턴 끝에 손에 있으면: …` — 상태 카드용(js/data/status-cards.js). 손에 든 채 턴을 넘기면 뒤가 돈다
- `사용 불가.` — 낼 수 없는 카드(상태 카드용)

**쓰지 않는다** — 읽히지 않거나 몸이 없다
`다음 턴 ~` · `코스트 -1`(다른 카드의) · `배율 +N%p` · `카드 생성` · `부활` · `추가 턴` · `골드` · `최대 HP 증가`
· `확률로` · `~당 N` (「X」 1당 피해 따위 — 키워드의 `1개당` 규칙으로 쓴다) · `주도` · `종극`(풀이가 없다)
· 조건문(`~하면`)은 카드 안에서 `「X」가 있으면` 하나뿐이다. 다른 조건은 패시브로.

## 6. 키워드 문법

```
**키워드 「X」** 설명 한 문장. [어디에] [최대 N.] [적의 차례가 끝나면 N 감소.] [1개당 …] [「X」가 N개가 되면: …]
```

첫 문장은 설명이다(사람이 읽는다). **그 뒤 문장은 모두 규칙이어야 한다** — 규칙이 아닌 문장은 검사에 걸린다.

| 어디에 | 쓰는 말 |
|---|---|
| 자기 주머니(기본) | 아무것도 안 적는다 — 간식·왕마력·겁 |
| 적에게 | `적에게 거는 표식이다.` — 늑대 표식·수족열증 |
| 아군에게 | `아군에게 거는 표식이다.` — 계시·물총 |

규칙:
- `최대 5.` · `적의 차례가 끝나면 1 감소.` · `적의 차례가 끝나면 전부 사라진다.` — 적이 친 **뒤에** 줄어든다(막는 표식이 적의 차례에 살아 있게). 옛 글 「턴 종료 시 N 감소」 도 같은 뜻으로 읽는다
- `1개당 자신 주는 피해 +5%.` · `1개당 자신 받는 피해 -4%.` · `1개당 자신 치명 확률 +4%.` · `1개당 자신 공격력 +5%.`
  (자기 주머니는 `자신`, 파티 전체에 걸려면 `1개당 아군 전원 주는 피해 +3%.`)
- 적·아군 표식: `1개당 받는 피해 +5%.` · `1개당 주는 피해 +6%.` · `1개당 턴 종료 시 공격력 30% 피해.`(지속 피해, 건 사람 공격력) · `1개당 턴 종료 시 회복(회복력 20%).`
- `「X」가 5개가 되면: 「X」 전부 소모, 적 전체에 공격력 150% 피해.` — 넘치면 터진다

`1개당` 값 × 최대치가 **40%를 넘지 않게** 한다.

**키워드는 무언가를 해야 한다** — `1개당` 규칙, `「X」가 N개가 되면`, 카드의 소모·조건 가운데 하나는 있어야 하고,
쌓는 곳(카드나 패시브의 `「X」 +N`)이 있어야 한다. 검사가 센다.

## 7. 수치 기준

스탯 기반 % 다(피해·회복 = 공격력 %, 방어·실드 = 방어력 %). 시작 카드가 기준이다.

| 코스트 | 공격 한 명 | 공격 전체 | 방어(자신) | 회복(한 명) |
|---|---|---|---|---|
| 0 | 60~80% | 40% | 120% | 40~50% |
| 1 | 100~140% | 60~80% | 200~250% | 70~90% |
| 2 | 200~260% | 120~150% | 350~450% | 130~160% |
| 3 | 320~400% | 180~220% | 550% | 200% |

- 부가 효과(상태·드로우·키워드)가 붙으면 그만큼 뺀다.
- **신탁**: ① 강화 = 수치 +30~50%p · ② 경량 = 코스트 -1 (아래 코스트 규칙) · ③ 연계 = 키워드와 맞물림 ·
  ④ 변형 = 대상·범위·역할을 바꾼다 · ⑤ 각성 = 판을 바꾸는 한 방, 대신 벌칙(소멸 · 키워드 전부 소모 · 스스로 받는 피해 + · HP 소모)
- **고학년 스킬**: 150%(한 명 강화·약화·작은 회복) · 200%(보통 광역 피해·파티 방어) · 250%(큰 광역·강한 파티 버프) · 300%(무적·전멸급)
- **패시브**: `항상` 은 15% 까지. 턴당 횟수 제한은 없다 — AP 는 턴에 한 번 도는 언제에만(§4 횟수). 매 턴 공짜로 강한 것(조건 없는 턴 시작 시 AP +1 따위)은 안 된다.
- 한 사도 안에서 네 장이 **서로 다른 일**을 한다. 넷 다 "적 1명에게 N% 피해"면 안 된다.

### 코스트 규칙 (검사기가 막는다)

전에는 고유 카드 72% 가 1코, 0코가 14%, 3코가 없었다. 평균 코스트(1.01)가 시작 카드(1.13)보다 낮아서
매 턴 1코 셋을 내면 끝났고, 0코는 드로우·키워드·게이지를 공짜로 줬다.

| 자리 | 기본 코스트 | ② 경량 |
|---|---|---|
| 시그니처(첫 장) | 1~2코 (또는 X) | 코스트 -1 |
| 큰 카드 | 2코, 어울리면 **3코** | 코스트 -1 |
| 보통 · 가벼운 카드 | 1코 | **0코** |
| 기본 0코 | **없다** | — |

- **0코는 신탁 ② 경량으로 얻는 보상이다.** 기본 카드는 1코 이상. ② 경량은 늘 `코스트 N.`(기본 -1)으로 시작한다.
- **3코는 사도당 한 장까지**, 원작에 "크게 한 방"이 있는 사도에게만(광역 폭격 딜러 · 버티는 전열 · 판을 뒤집는 서포터).
  한 턴을 다 쓰는 값을 해야 한다 — 한 명 320~400% · 전체 180~220% · 자신 방어 550% 에 **3코만의 것 하나**
  (광역 피해 + 기절, 파티 전원 큰 실드 + 디버프 해제, 키워드 한꺼번에 폭발 …). 연타·잔재주형 사도에게 억지로 넣지 않는다.
- **고유 카드 넷이 전부 1코면 안 된다** — 2코 이상(또는 X) 큰 카드가 적어도 한 장.
- **0코 신탁이 크면 소멸** — 값어치 1.0(1코 공격 한 명 120% 정도)을 넘는 0코는 `소멸` 을 붙인다.
- **무한 고리 막기**: AP 를 주는 카드는 신탁으로도 0코가 안 된다(② 경량은 대신 `보존.` 이나 `개전.`).
  0코 카드는 드로우 1까지 — 드로우 2 이상이면 `소멸` 을 붙인다.
- **값어치**: `tools/lib/card-value.js` 가 카드 효과를 대략의 값으로 센다(1코 공격 한 명 120% ≈ 1, 기준 = 0.5 + 코스트).
  기본 카드가 기준의 1.5배를 넘으면 검사에 걸린다(싸다). 3코는 0.8배 아래면 걸린다(비싸다).
- 보스는 기절한 다음 한 턴은 버틴다 — 기절로 보스를 묶어 두는 설계는 통하지 않는다.

  - `못 읽은 말: 「…」` — 그 말은 게임이 모른다. 위 표의 말로 바꾼다.
  - 조사 하나(「고」「2」)가 남으면 대개 글 모양 문제다 — `버리고`, `2턴간` 처럼 표의 모양 그대로 쓴다.
- 모두 끝나면: `node tools/merge-redesign.js` → `node tools/parse-design.js .omc/redesign/_기획서.md` → `node tools/build-cards.js`
  → `node tools/check-passive.js` (135명을 자동으로 싸워서 패시브가 실제로 발동하는지 센다)
