# 장비(아티팩트) · 교주 카드(스펠) — 다시 쓰는 법

원작 트릭컬의 **아티팩트 87종**(한국판 — 글로벌 전용은 뺐다)을 「장비」로, **스펠 카드 43장**을 「교주 카드」로 옮긴다.
원작은 오토 전투라 「초당 · 공격 속도 · 일반 공격 N회마다」 가 많다. 이걸 **덱빌딩식으로 다시 해석**한다 —
원작에서 *무엇을 강하게 하는 물건인가*(맛)는 살리고, 모양은 우리 전투 문법으로 바꿔서 **전부 실제로 돌게** 한다.

- 원작 글: `.omc/research/namu/_아티팩트.txt` · `_스펠.txt` (나무위키, 참고 자료 — 문장을 베끼지 않는다)
- 문법: [07-스킬구성.md](07-스킬구성.md) §4 패시브 · §5 효과 — 사도와 **같은 말**을 쓴다
- 검사: `node tools/check-gear.js 파일.md` — ✓ 가 될 때까지

## 1. 장비

```
#### 이름                                        ← 그대로
등급 · 칸 · [애착: 사도 ·] 원작: … — 한 줄 설명      ← 그대로
- **스탯** 공격 +2 · 치명 +6%                      ← 그대로(등급 예산이 이미 맞춰져 있다)
- **효과** 이름: [언제] [조건] 효과 (횟수)            ← 새로 쓴다 — 패시브 문법
- **애착 (사도)** 이름: [언제] [조건] 효과. Lv.3: 스탯   ← 새로 쓴다(애착 장비만) — 패시브 문법
```

**효과 줄은 낀 사도의 패시브가 된다.** 「이 사도의 카드」 = 낀 사도의 카드. 이름은 장비 이름에서 짧게(`차원의 힘:`).
두 가지를 하려면 ` · 이름: …` 로 잇는다(전설만).

**등급마다**

| 등급 | 효과 | 한도 |
|---|---|---|
| 일반 | **없음**(스탯만) — `- **효과** 없음(스탯 강화)` 그대로 두어도 된다. 있으면 `항상` 작은 것 하나 | 항상 4% |
| 고급 | 작은 것 하나. `항상` 도 되지만 조건 · 발동이 있으면 더 좋다 | 항상 6% · 발동 15% |
| 희귀 | **발동형**(언제 · 조건이 있다). 원작의 개성을 한 줄로 | 항상 8% · 발동 20% |
| 전설 | **발동형**, 판을 바꾸는 맛. 두 줄까지 | 항상 10% · 발동 30% |

- `항상` 만 있는 % 증감은 **희귀 · 전설에서 금지**(검사가 막는다) — 카드 N장마다 · 처치하면 · 맞으면 · HP N% 이하 · 턴 시작 시 따위와 엮는다.
- AP · 드로우 · 게이지를 주면 `(턴당 1회)` 나 `(전투당 1회)`. `전투 시작 시` 는 한 번뿐이라 괜찮다.
- 장비는 누구든 낄 수 있다 — **효과 줄에 사도 키워드(「간식」)를 쓰지 않는다.** 상태(취약 · 약화 · 기절 · 도발 …)는 된다.

**칸마다 맛**
- 무기 — 공격 쪽: 공격 카드 · 처치 · 연타 · 치명 · 적의 상태
- 방어구 — 버티는 쪽: 방어 · 실드 · 받는 피해 · 맞으면 · HP 낮을 때 · 도발
- 장신구 — 굴리는 쪽: 드로우 · 게이지 · 회복 · 연계 · 고학년 스킬 · 파티 버프

**번역 표**(원작 → 우리)

| 원작 | 우리 |
|---|---|
| 일반 공격 N회마다 | `공격 카드를 N장 낼 때마다` (N 은 3~4) |
| 공격 속도 | 드로우 · 「공격 카드를 낼 때마다」 쪽 |
| 스킬 피해 | 고유 카드 · 고학년 스킬 쪽 |
| 저학년 스킬 사용 시 | `고유 카드를 낼 때마다`는 없다 — `카드를 낼 때마다` · `스킬 카드를 낼 때마다` 로 |
| 고학년 스킬 | `고학년 스킬을 쓰면` |
| HP N% 이하면 무적 · 회복 | `HP가 30% 이하가 되면` (전투당 1회) |
| 처치 시 | `적을 처치하면` |
| 웨이브 시작 · 전투 시작 | `전투 시작 시` |
| 초당 회복 · 지속 | `턴 시작 시` · `턴 종료 시` |
| 보호막 | 실드 |
| 치명 피해 | 치명 확률(치명 피해는 150% 고정) |
| 즉사 · 처형 | `적을 처치하면` 보상 쪽으로 바꾼다(즉사는 몸이 없다) |

**애착** — 그 사도가 낄 때만 켜지는 패시브 한 줄. **그 사도의 키워드를 써도 된다**(「간식」 +1 따위). 원작 「애착 아티팩트 스킬」이
무엇을 강하게 했는지(저학년 강화 · 평타 강화 …)를 그 사도의 카드 · 키워드와 엮어서. 한도는 등급의 발동 한도.
줄 끝의 `Lv.3: 공격 +1 · 방어 +1 · 치명 +3%.` 는 그대로 둔다.

## 2. 교주 카드 (옛 이름 「중립 카드」 — 2026-10 이름을 바꿨다. 교주님이 직접 쓰는 카드)

```
#### 이름                                         ← 그대로
등급 · 가격 N골드 · 원작: … — 한 줄 설명            ← 그대로(가격도)
**이름** (코스트·타입[, 태그]) [덱에 1장만.] 효과     ← 카드 문법
- ① *이름*: 효과 전문                              ← 신탁 다섯 — 사도 고유 카드와 같은 자유 틀(분류 낱말 없음)
- ② *이름*: 코스트 N. 효과 전문
- ③ *이름*: 효과 전문
- ④ *이름*: 효과 전문
- ⑤ *이름*: 효과 전문
```

**신탁 다섯**(은총 · 신탁으로 뜬다 — [12-신탁.md](12-신탁.md)) — 사도와 같은 방향이 한 카드 안에 고루([11-사도리뉴얼.md](11-사도리뉴얼.md) §3)
- 가볍게 — 코스트 -1(최소 1) · 드로우 · 보존 · 개전. **0코로 내리지 않는다**(0코는 원작 SP 사도만, §3-2)
- 무겁게 — 코스트를 올리고 기본의 1.6배 이상, 3코 위 금지, 소멸 같이 금지, 2코 이상에 드로우 금지
- 역할 넘기 — 딜 ↔ 보호 · 회복
- 키워드 대신 **새 규칙과 맞물리는 갈래** — 즉시 행동 -N(그 턴 안에서만 — 내 턴이 시작되면 적의 카운트는 0 으로 돌아간다) · AP(+1 까지) · 고학년 게이지(+100% 까지) · 덱 무게
- 개성 — 원작 설명 · 설정

- 교주 카드는 주인이 없다 — 피해 · 방어 · 회복은 **공격력 · 방어력이 가장 높은 아군 기준**(쓰지 않아도 그렇게 돈다). 「자신」 = 그 아군.
- 타입: 공격 · 스킬 · 방어 · 회복 · 강화. 코스트는 **카드 무게대로 1~3**(큰 효과 2~3 · 굴리는 것 1, X 도 된다). 기본 0코 없음.
- `이번 전투 동안` 증감을 주면 **`덱에 1장만.` + `소멸`**(강화 카드). 한도: 전설 15% · 희귀 10% · 고급 8% · 일반 5%.
- 값어치: 코스트 기준의 **0.6~1.6배**(`tools/lib/card-value.js`). 등급이 높을수록 위쪽 — 일반 1.0 · 고급 1.15 · 희귀 1.3 · 전설 1.45 정도.
- 쓰지 않는다: 골드 · 최대 HP 증가 · 카드 생성 · 확률 · 다음 턴 ~ (§5 「쓰지 않는다」와 같다). 원작이 그런 카드면 맛만 살려 다른 모양으로.
- 사도 키워드 금지. 성격의 카드[광기] 등 성격 카드는 「그 성격 사도가 하는 일」을 아군 전원에게 나눠 주는 식으로.

## 3. 검사와 합치기

1. 조각 파일(`.omc/gear/*.md`)을 고친다 — 머리 · 원작 · 스탯 · 가격 줄은 **한 글자도 안 바꾼다**
2. `node tools/check-gear.js .omc/gear/<파일>.md` 가 전부 ✓
3. `node tools/merge-gear.js` 가 기획서의 두 탭에 되돌려 넣는다 → `parse-design` → `build-cards` → `check-gear`(기획서)
