# 낱말 — 트릭컬 것으로 쓴다

얼개는 카오스 제로 나이트메어에서 빌려 왔지만 **낱말까지 빌려 오면 안 된다.**
한동안 도감 머리에 「모든 세력」이라고 적혀 있었다. 트릭컬에 세력이라는 구분은 없다.

원본은 **기획서**(저장소 맨 위의 `트릭컬_기획서_전체.md`)와
[docs/03-세계관.md](03-세계관.md) 다. 헷갈리면 기획서가 쓴 낱말을 쓴다.

## 바꾼 것

| 빌려 온 말 | 우리가 쓰는 말 | 왜 |
|---|---|---|
| 세력 | **종족** | 기획서에 세력이라는 구분이 없다. 요정·엘프·수인·마녀·용족·정령·유령·미스틱 여덟이 그 자리다 |
| 모든 세력 | **모든 종족** | 〃 |
| 열 | **위치** | 기본 스탯 표 머리가 「위치 · 역할」이다 |
| 앞 · 가운데 · 뒤 | **전열 · 중열 · 후열** | 기획서가 그렇게 쓴다. 전투 화면만 따로 「앞줄」이라 부르던 것을 맞췄다 |
| 등급 | **성급** | 「성급 보정: 3성 ×1.0 · 2성 ×0.9」. 등급은 **장비 희귀도**(일반·고급·희귀·전설)에 쓴다 |
| 상세 정보 | **사도 정보** | 카제나 화면 이름이었다 |
| 전투원 · 파트너 | **사도 · 이격** | 카제나의 탭 이름이었다. 이격은 트릭컬 말이다 |
| 에고 스킬 | **고학년 스킬** | 카제나 말. 트릭컬 인게임으로는 고학년 스킬이다 |
| WORLD TREE EXPEDITION 따위 | (걷어냄) | 뜻 없는 영어 장식 |
| 세 왕국 | **세 지역** | 모나티엄은 엘프 **도시**고 벨리티엔은 마녀의 땅이다. 왕국은 에르피엔뿐이다 |

## 그대로 두는 것

트릭컬 말이거나 기획서가 정한 말이다.

**사람과 자리** 사도 · 이격 · 교주 · 엘다인 · 편성
**분류** 성격(순수 · 광기 · 냉정 · 우울 · 활발 · 공명) · 종족 · 역할(탱커 · 딜러 · 서포터) · 위치 · 성급
**전투** AP · 고학년 게이지 · 방어 · 실드 · 취약 · 약화 · 기절 · 도발 · 치명
**카드** 시작 카드 · 고유 카드 · 시그니처 · 신탁(①강화 ②경량 ③연계 ④변형 ⑤각성) · 기적
**지명** 에르피엔(요정 · 세계수 주변) · 모나티엄(엘프 · 동부) · 벨리티엔(마녀 · 세계수 뿌리) ·
수인 부락 · 정령산 · 유령 늪 · 불길과 물길의 터
**그 밖** 주말농장(쓰러짐) · 골드 · 엘리프

## 지어내면 안 되는 것

- **지명** — 위 일곱 곳뿐이다. 새로 지으면 `npm run world` 가 잡는다
- **죽음** — 죽다·주검·무덤을 쓰지 않는다. 쓰러지면 **주말농장**에 간다
- **남성 지칭** — 지성체는 전부 여성이다 (엘프만 지구에서 산타를 겪어 남성을 안다)
- **계절** — 늘 봄에 가깝다. 겨울·눈을 층 이름에 쓰지 않는다

## 카드 글의 밑줄

카드에 나오는 낱말 가운데 풀이가 있는 것에는 점선 밑줄이 그어지고, 누르면 쪽이 뜹니다.
풀이는 `js/data/keywords.js` 에 모여 있고 `npm run keywords` 가 기획서에서 다시 만듭니다.

**개전 · 종극 · 주도 · 보존 · 소멸** 다섯은 기획서에 이름만 있고 풀이가 없습니다.
지어내지 않고 비워 두었습니다 — 규칙을 정하면 그때 기획서에 적고 다시 돌리면 됩니다.

## 검사

```
npm run kwcheck   # 밑줄이 제자리에 그어지는지 본다
npm run smoke     # 화면에 빌려 온 낱말이 도로 끼어들지 않았는지 본다
npm run world     # 카드 이름·설명·층 이름·사도 소개를 세계 규칙에 대고 훑는다
```
