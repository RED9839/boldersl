# 스파인 — 자리마다 다른 그림

전투에는 인게임 SD, 이벤트·상점에는 스탠딩, 맵 이동에는 미니미를 쓴다.
셋 다 **부품 단위 스파인**이라(에르핀 스탠딩만 163개) 그림 한 장으로는 못 쓰고 런타임이 있어야 움직인다.

사도 데스크와 같은 방식이다 — `.skel` + `.atlas` + 텍스처를 그대로 두고 spine-webgl 4.1 이 굴린다.

## 정리

```
npm run spine        # 꺼내 둔 것 중 편성 여덟 + 미니미만 골라 assets/spine/ 으로
npm run spine:check  # 정리한 것이 실제로 읽히는지
```

1.8GB 중 게임이 물고 있는 건 **29.6MB** 다.

```
assets/spine/
  manifest.json          무엇이 있는지
  ingame/<사도>/         전투 SD   (.skel · .atlas · 텍스처)
  standing/<사도>/       스탠딩
  minimi/                미니미 — 한 아틀라스를 모두가 나눠 쓴다(431명)
```

`build-spine.js` 는 텍스처 이름을 **아틀라스 안에서 읽는다.** 파일 이름을 짐작해 고르면 언젠가 어긋난다.

## 검사

`npm run spine:check` 는 있는지만 보지 않는다. 그림이 안 나오는 사고는 대개
"파일은 있는데 안이 비었다" 쪽이라서다.

- 아틀라스가 가리키는 텍스처가 다 있는가
- `.skel` 이 스파인 4.x 인가, 그리고 런타임(package.json 의 spine-webgl)과 부 버전이 같은가 — 게임은 4.1 이고 4.2 부터는 바이너리가 안 읽힌다
- 텍스처가 진짜 PNG 인가 (머리 바이트)
- 아틀라스에 영역이 들어 있는가
- **미니미 아틀라스에 편성 여덟이 다 있는가**

## 그림이 없으면 떨어진다

`js/art.js` 가 한 단계씩 떨어뜨린다 — 이건 설계다.

```
스파인(움직임) → 그림 한 장 → SD → 색과 이름
```

런타임이 없어도, 아무것도 안 꺼내 뒀어도 게임은 돈다.
`art.setSpine(false)` 로 스파인만 꺼 볼 수도 있다.

## 미니미는 잘라 쓸 수도 있다

미니미만은 아틀라스 하나에 캐릭터마다 영역이 통째로 들어 있어서, 런타임 없이 잘라내도 된다.

```
npm run minimi                       # 편성 여덟
python tools/build-minimi.py --all   # 431명 전부
```

움직이지 않는 대신 가볍다. 스파인이 없을 때 이쪽으로 떨어진다.

## 런타임 라이선스 — 짚고 갈 것

**Spine Runtimes 는 쓰는 사람이 각자 Spine Editor 라이선스를 가져야 한다.**
`vendor/spine-webgl.LICENSE` 원문:

> it is permitted to integrate the Spine Runtimes into software … provided that
> **each user of the Products must obtain their own Spine Editor license** and
> redistribution of the Products in any form must include this license and copyright notice.

사도 데스크는 소스 배포라 받는 쪽이 각자 갖추면 됐다. **웹게임은 다르다** — 링크를 열면
누구나 런타임을 내려받게 되니, 그 사람들이 전부 라이선스를 가진 게 아니다.

처음에는 공개 배포를 미뤄 두었다. **2026-10-01, 웹 공개판(https://bolzena.pages.dev)에 스파인을 그대로 싣기로 했다** —
다른 트릭컬 팬게임들처럼 비영리 · 저작권 표기 · 요청 시 즉시 내림으로 간다(사용자 결정).

- 런타임은 `vendor/` 에 라이선스 원문과 함께 두고, 공개판에도 원문(`vendor/spine-webgl.LICENSE`)을 같이 올린다
- 권리자(EPID Games · Esoteric Software)가 문제 삼으면 `art.setSpine(false)` 판으로 바꾼다 —
  미니미는 잘라 둔 것이 있고, 전투·이벤트는 heroicons 로 떨어진다
- 참고로 스파인 없이 움직이게 하는 길도 있다 — 원작 애니메이션을 프레임 시트로 구워 넘기는 것(다른 팬게임 「팝엔 페인트」가 이렇게 한다).
  런타임 조건은 피하지만 용량이 크고 실시간 교감(본 끌기)은 못 한다
