# 볼더슬 — 규칙 (v0.2 · 2026-09-29 리뉴얼 반영)

> 트릭컬 리바이브 팬 로그라이크 덱빌더. 비공식 개인 프로젝트.
> 플레이어는 **교주**이고, 사도 셋을 데리고 한 판(런)을 돈다.

**원본은 기획서다.** 전투 규칙과 수치는 저장소 맨 위의 `트릭컬_기획서_전체.md`(「전투 규칙」·「수치 체계」)와
`트릭컬_리뉴얼_규칙.md` 가 정하고, 코드는 [js/rules.js](../js/rules.js) 가 그 값을 옮겨 쓴다.
이 문서는 **왜 그렇게 했는지**와 기획서에 없는 우리 몫(층 구성 따위)을 적는다.
둘이 어긋나면 기획서가 맞다.

## 왜 이 구조인가

슬더스 계열에서 한 캐릭터가 덱을 통째로 들고 가는 방식 대신 **파티 편성**을 골랐다 — 원작처럼 사도 셋이
저마다 카드 넉 장을 들고 와 한 덱을 이룬다. (처음에는 원작 음성 데이터로 짝마다 「사이」를 매겨 연계를 붙였는데,
짝이 몇 사도에게 몰려 걷어 냈다 — 아래 「사이(관계) — 걷어 냈다」.)

## 한 판의 흐름

```
편성(사도 3명) → 에르피엔 → 모나티엄 → 벨리티엔
                 요정 왕국   엘프 도시   마녀 왕국·세계수 뿌리
```

층은 지어낸 곳이 아니다. **엘리아스의 실제 지도**에서 온다 — 세계관과 지명 규칙은
[docs/03-세계관.md](03-세계관.md).

- 한 층: 전투 → 전투 → **캠프** → 전투 → **캠프 + 골디의 상점** → 보스([09-상점.md](09-상점.md)). 처음 고른 셋으로 끝까지 간다 — 층 사이 사도 교체는 없앴다(2026-10-01). 고학년 게이지는 전투가 끝나도 이어진다
- 전투에서 이기면 **그 파티 사도의 고유 카드** 셋 중 하나를 고른다. 가끔 신탁이 뜬다(아래)
- 셋이 다 쓰러지면 판이 끝난다. 엘리아스에는 죽음이 없으니 **주말농장에 다녀오는 것**이고,
  해금은 다음 판으로 이어진다

## 어디서 무엇을 가져왔나

| | 무엇을 |
|---|---|
| **슬레이 더 스파이어** | 손패 5, 뽑을 것/버린 것 더미, 턴마다 사라지는 방어, 적의 의도 표시, 전투 후 카드 보상 |
| **카오스 제로 나이트메어** | 사도 셋이 한 덱을 이룬다 · 카드마다 붙는 **신탁**과 그 위의 **기적** · 편성·도감·전투 화면 구성 |
| **다키스트 던전** | 줄(전열·중열·후열)과 줄을 따지는 카드 |
| **트릭컬 리바이브** | 사도·스킬(저학년 → 시그니처, 고학년 → 고학년 스킬)·성격 상성·아티팩트(→ 장비)·몬스터 |
| **우리 것** | 같은 열 자리 바꾸기 |

## 전투

턴제, 카드.

- **AP** 파티 공용, 매 턴 3. **남으면 사라진다**(이월 없음). 카드 코스트는 AP
- **손패** 매 턴 5장을 뽑는다. 손에는 열 장까지 — 넘치게 뽑은 카드는 사라진다
- **위치는 고정이다.** 사도마다 전열·중열·후열이 정해져 있고 바꿀 수 없다. 적은 기본적으로 전열부터 노린다.
  같은 열에 둘 이상이면 편성에서 ⇄ 로 자리를 바꿀 수 있고, **적 쪽에 선 사도가 먼저 맞는다**(뒤를 노리는 수는 가장 안쪽부터). 열이 주는 효과 · 조건은 자리와 상관없이 열만 본다
- 체력·방어는 사도마다 따로다. **쓰러진 사도의 카드는 그 전투에서 쓸 수 없다**
- 상태: 약화(주는 피해 -10%) · 취약(받는 피해 +10%) · 기절 · 도발 · 방어(턴 종료 시 소멸) · 실드(유지)

### 카드는 사도에게 속한다

덱 = 편성한 사도 셋의 카드. 사도를 바꾸면 덱이 바뀐다.

**사도 한 명당 여덟 장** — 편성하면 바로 들어오는 **시작 카드 넷**(기본공격·강공격·방어·회복을 역할에 맞게),
판을 돌며 얻는 **고유 카드 넷**(첫 장은 시그니처 = 인게임 저학년 스킬). 기획서는 제거·복제로 덱을
자유롭게 깎게 한다(아직 화면은 없다).

시작덱은 정의 순서에 기대지 않고 적어 둔다. 카드를 새로 끼워 넣을 때마다
시작덱이 조용히 바뀌는 일을 한 번 겪었기 때문이다.

### 고학년 스킬 — 덱 밖에 있다

인게임 **고학년 스킬**이 고학년 스킬이다. 덱에 들어가지 않고, **고학년 게이지**를 써서 AP 없이 쓴다.

```
게이지  파티 공용 0~300% · 카드에 쓴 AP 1당 +10% · 0코 카드는 충전 없음 · 전투가 끝나면 0%
비용    150% · 200% · 250% · 300% (효과 크기로 정한다)
        같은 사도의 고학년 스킬은 연속으로 쓸 수 없다
```

AP 가 이월되지 않는 대신 **모으는 판단은 게이지가 맡는다** — 지금 카드를 더 내느냐,
게이지를 채워 큰 고학년 스킬을 노리느냐.

## 수치 — 스탯 기반 %

카드 효과는 사도 스탯에 대한 % 다(피해 = 공격력 %, 방어·실드 = 방어력 %, 회복 = 공격력 %).

```
최종 피해 = 스탯 × (카드 배율 + 신탁) × 기적(×1.3) × (1 + 전역 증가) × 치명(×1.5)
```

- **치명** 피해는 150% 고정. 확률은 딜러 10%, 그 외 5%. 치명 피해를 올리는 효과는 없다
- **전역 증가·감소**(장비·교주 카드·상성·취약·약화·아군 버프)는 같은 종류끼리는 가장 큰 값 하나만,
  다른 종류끼리는 더한다. 한 효과는 5~10%, 조건부·전투당 1회는 최대 15%
- 기본 스탯은 위치와 역할에서 나온다(전열 탱커 HP 90 · 후열 딜러 HP 55). 표는 기획서 「수치 체계」

### 원작 수치는 옮기지 않는다

원작의 공격력·체력·스킬 계수는 위키에 다 있다. 그런데 **그대로 옮기지 않는다.**
원작은 9명 실시간 자동 전투이고 이건 3명 턴제 카드 게임이다. 엘레나 저학년 585% 는
그 규칙 위에서만 뜻이 있다. 게임 안의 표 데이터(`table`)가 암호화돼 있는 것도 결과적으로는
상관이 없다 — 풀어도 쓸 수치가 아니고, **보호를 푸는 일은 하지 않는다.**

| 가져온다 | 가져오지 않는다 |
|---|---|
| 누가 무엇을 하는 사람인가 (여왕·사제장·공학자·검사) | 공격력·체력·방어력 수치 |
| 스킬이 **무엇을 하는가** (관통·감전·소환·중독) | 스킬 계수·쿨타임 |
| 성격(속성)과 포지션 | 등급별 수치 |
| 누가 누구와 얽혔는가 · 하지 않는 일 (`never`) | |

**무엇을 하는가는 원작, 얼마나 세게는 우리 자**다.

## 성격 — 상성이다

트릭컬의 **순수·광기·냉정·우울·활발**(그리고 공명)을 쓴다. 기획서 규칙은 **상성**이다.

```
광기 → 순수 → 냉정 → 광기      유리하면 주는 피해 +10%, 받는 피해 -5%
활발 ↔ 우울                    서로 +10%
공명                           상성 없음
```

성격 패시브 · 성격 시너지 · 종족 효과는 **없다.**

성격은 `bible.json` 의 `facts` 에 `성격 분류: X` 로 적혀 있고(138명 중 126명),
기획서의 사도 표가 그 위에 온다. 게임 파일에서도 같은 체계가 확인된다 — 꺼낸 몬스터 아이콘 410장 중
**227장**이 `naive / mad / cool / gloomy / jolly` 꼬리표를 단다. 그래서 `js/data/enemies.js` 의 적에도 성격이 적혀 있다.

## 사이(관계) — 걷어 냈다

한때 이 게임의 핵심으로 두었다. 사도 데스크의 `relations.json`(게임 음성 대사에 두 사도가 함께 나온 횟수 ·
서로 부르는 말)으로 짝마다 각별 · 친함 · 안면 · 초면을 매기고, 다른 사도의 카드를 이어 내면 **연계**(×1.35 · ×1.2 · +2),
각별한 짝이 있으면 **첫 턴 AP +1** 을 줬다.

135명 전체 9,045짝을 세어 보니 각별 7짝 · 친함 56 · 안면 381 · **초면 8,601(95%)**, 짝이 하나도 없는 사도가 47명 —
음성 대사가 많은 몇 사도에게 몰린 보너스였고, 그걸 풀어 줄 이벤트도 없었다. 그래서 통째로 뺐다.
`relations.json` 은 성격 보조 자료로만 남는다(`js/combat.js` natureOf).

## 신탁과 기적

**신탁**은 **고유 카드마다 다섯**이 붙어 있다 — ① 강화 · ② 경량 · ③ 연계 · ④ 변형 · ⑤ 각성.
시작 카드에는 없다. 한 카드에 하나만 붙는다.

- 전투 보상 때 **무조건 뜨지 않는다.** 기획서에 확률값이 없어서 `FLASH_CHANCE = 0.35` 로 우리가 정했다
  (한 판 보상 열두 번에 네 번쯤)
- 뜨면 **이미 가진 고유 카드** 하나를 골라, 다섯 중 무작위 셋을 보여 주고 하나를 고르게 한다

**기적**은 신탁 위에 드물게 한 줄을 더 얹는다(수치는 ×1.3 곱연산). 신탁 선택지 셋 중 하나가
낮은 확률(기본 5%)로 기적이 된다. 값은 `SHIN_CHANCE` 로 적어 뒀지만 풀을 아직 파서로 읽지 않아
**게임에서는 아직 안 뜬다.**

## 장비 — 원작의 아티팩트

기획서는 원작 아티팩트 87종(한국판 — 글로벌 서버 전용은 뺐다)을 **장비**로 옮겼다(「아티팩트 → 장비」 탭). 스탯 % 방식이고,
피해 증가는 전설 10% · 희귀 7~8% · 고급/일반 5%.

**1단계가 들어갔다**(자세한 것은 [09-상점.md](09-상점.md) 의 「장비」).
87종을 파서가 읽고, 칸 세 개와 **스탯 줄**, 애착 사도가 낄 때의 **Lv.3 스탯**이 돈다.
드랍 · 골디의 상점 · 이벤트에서 얻는다. 전투 밖이면 어디서든 끼고 빼고 바꿔 낀다. 가방의 장비는 사는 값의 40% 에 판다.
**효과 줄 · 애착 줄**은 패시브 문법으로 다시 써서 낀 사도의 패시브로 붙는다([13-장비와 중립.md](13-장비와%20중립.md)). 일반 몇 종만 스탯뿐이다.
그림은 원작 아티팩트 아이콘(tools/extract-gear-icons.py · tools/gear-icons.json).
리뉴얼 전 **유물**(SP 를 주던 `relics.js`)은 걷어 냈다.

## 사도의 카드는 원작 스킬에서 나온다

처음에는 `bible.json` 의 성격 설정만 읽고 카드를 지어냈다. 나무위키를 보니 사도마다
**실제 스킬과 포지션과 공격 타입**이 있었고, 내가 지어낸 것과 꽤 달랐다. 전부 갈아엎었고,
지금은 135명 전원이 원작 스킬에서 나온다 — 저학년 → 시그니처, 고학년 → 고학년 스킬,
강화 평타·어사이드·애착 아티팩트 → 패시브와 키워드. 무엇을 어디로 가져왔는지는 기획서의 **원작** 줄에 적혀 있다.

지어낸 것과 달랐던 곳 몇 가지:

- **프리클은 탱커가 아니라 소환사였다.** 가시로 되받아치는 게 아니라 촉수를 불러 대신 싸우게 한다
- **마요의 독은 지속 피해가 아니라 공격력 감소(중독)였다.** 깎아서 파티를 지키는 쪽이다
- **에르핀은 중열 힘캐가 아니라 후열 마법 딜러였다.** 결계를 주먹으로 부수는 건 설정이고, 싸울 땐 마법을 쓴다
- **네르는 탱커가 아니라 버프 서포터였다.** 아군의 피해량을 올리는 게 본업이다
- **감전은 엘레나와 아멜리아를 잇는 실제 게임 내 시너지였다.** 이 둘은 우리 관계 데이터에서도
  각별(30편)이다 — 원작의 두 체계가 같은 곳을 가리킨다

문법과 수치 기준은 [docs/07-스킬구성.md](07-스킬구성.md).

## 적도 지어내지 않는다

꺼내 둔 몬스터 아이콘 410장에 **231종**의 진짜 이름이 있다. "굴러다니는 무언가" 같은 것을
쓸 이유가 없다. 지금 쓰는 적은 전부 실제 몬스터다 — 요정 무리, 인삼, 먹보곰, 엘프 병사,
경비 드론, 늙은 나무, 위습, 커버러스, 골렘, 이무기, 그리고 **저주 인형**.

저주 인형이 특히 그렇다. 요정·엘프·수인·유령·정령·마녀·용족·미스틱 **여덟 종족 전부**에 대해
딜러·서포터·탱커·술사 네 역할씩 있다. 파일이 `icon_<이름><성격>.png` 꼴이라
`tools/build-art.js` 가 그 적의 성격에 맞는 그림을 골라 온다.

## 세계 규칙을 기계가 지킨다

트릭컬에는 정리된 세계 규칙이 있다(죽음이 없다·지성체는 전부 여성·눈이 안 내린다·
지명은 정해져 있다…). 문서에 적어 두기만 하면 지켜지지 않아서, 사도 데스크의
`world-check.js` 를 가져와 **이 게임의 글에 걸었다** — 카드 이름과 설명, 층 이름, 사도 소개,
적의 의도 표시까지.

```
npm run world
```

검사기 자체가 틀릴 수 있어서 붙박이 시험을 넣어 뒀다. 실제로 한 번 틀렸다 —
`죽이` 패턴이 **`죽일`을 못 잡았다.** 이제 `죽[었는을어음이일인여]` 로 잡고,
반죽·뒤죽박죽·죽순은 통과시킨다.

가장 큰 것은 **죽음이 없다**는 규칙이다. 쓰러진 사도는 죽지 않는다 — **주말농장에 간다.**
완곡어가 아니라 그 말밖에 없어서 나오는 화법이라, 돌려 말하는 티가 나면 틀린 것이다.

## 그림은 갈아 끼운다

`art-adapter` 하나로 분리한다. 게임 코드는 "사도 키"만 알고, 무엇을 그릴지는 어댑터가 정한다.

| 자리 | 쓰는 그림 |
|---|---|
| 전투 | 인게임 사도 SD |
| 맵 이동·교체 | 미니미 |
| 이벤트·상점 | 스탠딩 일러스트 |

그림이 없으면 한 단계씩 떨어진다 — 자리 그림 → SD → 색과 이름.
이렇게 두면 나중에 어느 쪽으로 가든 게임이 멈추지 않는다. 사도 데스크에서 배운 것이다.
