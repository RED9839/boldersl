# 골디의 상점

층마다 **보스 앞에서 한 번** 들르는 상점. 주인은 **골디** — 황금에서 태어난 용족 상인이자 교단 상점 담당이다.
인물 사전(사도 데스크 `bible.json` 의 `goldy`)을 그대로 따른다.

| 설정 | 상점에서 |
|---|---|
| 정품만 취급하는 가장 청렴한 상인 | **효과가 다 도는 카드만** 진열한다(아래) |
| 할인 요구에는 웃으며 단호하다 | 「깎아 주세요」를 누르면 거절한다. 값은 기획서 그대로 |
| '고객님'이라 부르고, 말하다 말고 와작(보석을 씹는다) | 대사 |
| 돈에 쩨쩨하지 않다 · 실비아는 수양딸('황금대공') | 파티에 **실비아**가 있으면 한 판에 한 번 **선물**(일반·고급 중립 카드 한 장). 할인이 아니라 선물이다 |
| 비비·시스트·시온·피라·리츠·클로에·에슈르와의 관계 | 그 사도가 파티에 있으면 먼저 건네는 말이 바뀐다 |
| 본업은 금세공 | 카드 제거 대사 — 「필요 없는 걸 덜어 내는 게 제일 좋은 세공이에요」 |

## 파는 것

| | 몇 | 값 |
|---|---|---|
| **중립 카드** | 3 (등급 가중: 일반 5 · 고급 4 · 희귀 2 · 전설 1) | 기획서 「스펠 → 중립 카드」 의 골드 그대로 |
| **고유 카드** | 파티 사도 것 중 없는 것 2 | 75 골드 (시그니처 110) |
| **카드 제거** | 들를 때 한 번 | 75 골드, 쓸 때마다 +25 |

「덱에 1장만」 카드는 이미 덱에 있으면 진열하지 않는다.

## 골드

| | |
|---|---|
| 시작 | 99 |
| 보통 싸움 | 15~25 (층이 오를수록 +5) — 카드를 안 골라도 받는다 |
| 보스 | 75 |

기획서는 중립 카드 값만 적었다. 버는 쪽과 서비스 값은 **우리가 정했다**(`js/rules.js`).

## 중립 카드 — 43장 중 10장만 판다

중립 카드는 이제 파서가 읽는다(`tools/lib/neutral-block.js` → `design.js`·`built.js` 의 `neutral`).
그런데 **효과 글이 한 글자라도 안 읽힌 카드는 팔지 않는다.** 「전열 아군」 에서 「전열」 을 못 읽으면
전원에게 걸리고, 「물리 아군」 을 못 읽으면 아무에게나 걸린다 — 반쯤 읽힌 카드는 틀리게 돈다.

지금 파는 10장: 전술 교본 · 단체 월반 · 아로마 테라피 · 안 아프게 맞는 법 · 방탄불괴 · 저놈 잡아라! ·
학자 · 회심의 일격 · 그건 내 잔상 · 자기 계발.
나머지 33장은 규칙이 붙는 대로 진열대에 오른다(`npm run build` 가 몇 장인지 센다).

주인이 없는 카드라 **공격력·방어력이 가장 높은 아군 기준**으로 돈다(기획서 규칙). 피해·회복은 공격력이 가장 높은
아군, 방어·실드는 방어력이 가장 높은 아군을 본다. 번뜩임(① 강화 · ④ 변형)은 읽어 두기만 하고 아직 안 붙는다.
