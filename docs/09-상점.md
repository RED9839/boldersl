# 캠프와 골디의 상점

## 한 층의 흐름

```
전투 → 전투 → 캠프 → 전투 → 캠프 + 상점 → 보스
```

**캠프**에서는 하나만 고른다(슬더스 모닥불).

| | |
|---|---|
| 쉬기 | 살아 있는 사도 HP +30%(최대 HP 기준). 쓰러진 사도는 주말농장에서 쉬는 중이라 안 찬다 |
| 수련 | 가진 고유 카드 하나에 신탁 — 다섯 중 셋을 보여 준다(보상의 신탁과 같다). 고유 카드가 없으면 못 한다 |

**캠프 + 상점**은 보스 앞이다. 골디가 캠프 옆에 좌판을 폈다. 상점에 들러도 캠프 선택은 그대로 남고,
상점에서 나오면 캠프로 돌아온다. 회복량은 기획서에 없어 우리가 정했다(`CAMP_HEAL`).

## 골디의 상점

층마다 **보스 앞 캠프에서 한 번** 들르는 상점. 주인은 **골디** — 황금에서 태어난 용족 상인이자 교단 상점 담당이다.
인물 사전(사도 데스크 `bible.json` 의 `goldy`)을 그대로 따른다.

| 설정 | 상점에서 |
|---|---|
| 정품만 취급하는 가장 청렴한 상인 | **효과가 다 도는 카드만** 진열한다(아래) |
| 할인 요구에는 웃으며 단호하다 | 「깎아 주세요」를 누르면 거절한다. 값은 기획서 그대로 |
| '고객님'이라 부르고, 말하다 말고 와작(보석을 씹는다) | 대사 |
| 돈에 쩨쩨하지 않다 · 실비아는 수양딸('황금대공') | 파티에 **실비아**가 있으면 한 판에 한 번 **선물**(일반·고급 교주 카드 한 장). 할인이 아니라 선물이다 |
| 비비·시스트·시온·피라·리츠·클로에·에슈르와의 관계 | 그 사도가 파티에 있으면 먼저 건네는 말이 바뀐다 |
| 본업은 금세공 | 카드 제거 대사 — 「필요 없는 걸 덜어 내는 게 제일 좋은 세공이에요」 |

## 파는 것

| | 몇 | 값 |
|---|---|---|
| **교주 카드** | 3 (등급 가중: 일반 5 · 고급 4 · 희귀 2 · 전설 1) | 기획서 「스펠 → 교주 카드」 의 골드 그대로 |
| **고유 카드** | 파티 사도 것 중 없는 것 2 | 75 골드 (시그니처 110) |
| **카드 제거** | 들를 때 한 번 | 100 골드 고정(횟수로 오르지 않는다 — 2026-10) |

「덱에 1장만」 카드는 이미 덱에 있으면 진열하지 않는다.

## 골드

| | |
|---|---|
| 시작 | 99 |
| 보통 싸움 | 15~25 (층이 오를수록 +5) — 카드를 안 골라도 받는다 |
| 보스 | 75 |

기획서는 교주 카드 값만 적었다. 버는 쪽과 서비스 값은 **우리가 정했다**(`js/rules.js`).

## 교주 카드 — 43장

교주 카드는 파서가 읽는다(`tools/lib/neutral-block.js` → `design.js`·`built.js` 의 `neutral`).
**효과 글이 한 글자라도 안 읽힌 카드는 팔지도 떨구지도 않는다**(`playable`) — 지금은 43장 전부 읽힌다.
다시 쓰는 법은 [13-장비와 중립.md](13-장비와%20중립.md).

주인이 없는 카드라 **공격력·방어력이 가장 높은 아군 기준**으로 돈다. 신탁 다섯(① 강화 ② 경량 ③ 연계 ④ 변형 ⑤ 각성)이
고유 카드처럼 붙는다 — 덱에 있으면 전투 중 신탁이 뜬다.

## 장비

기획서 「아티팩트 → 장비」 87종(무기 30 · 방어구 20 · 장신구 37 — 글로벌 서버 전용은 뺐다). 사도마다 **무기 · 방어구 · 장신구 한 칸씩.**

| 무엇이 도나 | |
|---|---|
| **스탯 줄** | 87종 전부. HP 는 한 판의 최대 HP 에 바로 들어가고(지금 HP 도 그만큼 찬다), 공격·방어·치명은 전투를 열 때 더한다 |
| **효과 줄** | 패시브 문법 — 낀 사도의 패시브로 붙는다. 일반 몇 종만 스탯뿐 |
| **애착** | 이름에 붙은 사도가 끼면 애착 줄(패시브)과 Lv.3 스탯이 더 붙는다. 끼울 사도 단추에 ♥ |

## 드랍 — 적이 쓰러질 때 떨어지는 것(`R.DROP`)

보상 화면은 없다. 쓰러진 적이 골드를 떨구고, **가장 센 적**이 들고 있던 장비를 떨군다.
오른쪽 「얻은 것」 목록에 쌓이고, 이기면 그대로 챙긴다(장비는 가방으로). 한 싸움에 장비는 **하나까지**. **같은 장비도 다시 나온다** — 드랍 · 상점 · 이벤트 모두(마법 딜러 둘이 같은 지팡이를 하나씩 낄 수 있게).
**교주 카드는 싸움에서 떨어지지 않는다** — 골디의 상점과 이벤트에서만 얻는다(덱이 저절로 불지 않게).

| 싸움 | 골드 | 장비 |
|---|---|---|
| 일반 | 15~25 (+층×5) | **22%** — 1층 일반 · 2층 일반/고급 · 3층 고급/희귀 |
| 엘리트 | ×1.5 | **늘** — 1층 일반/고급 · 2층 고급/희귀 · 3층 희귀/전설 |
| 보스 | 75 | **늘** — 1층 고급/희귀 · 2층 희귀/전설 (마지막 보스는 판이 끝나니 없음) |
| 이벤트 싸움 | — | — |

한 층에 지나는 칸(지도 500판 평균): 일반 5.6 · 엘리트 1.1 · 보스 1. 그래서 층마다 대략
**장비 3.3** — 사도 셋 × 세 칸 = 아홉 칸을 세 층에 걸쳐 채운다. 여기에 골디의 상점이 더한다.

| 상점 | |
|---|---|
| 골디의 상점 | 교주 카드 셋 · 고유 카드 둘 · 장비 한 점(일반 90 · 고급 130 · 희귀 180 · 전설 250 골드) · 카드 제거 |

**끼는 규칙** — 기획서: 「휴식 노드에서 바꿔 낀다」. 그래서 얻은 자리에서는 **빈 칸에만** 바로 끼고,
끼기 · 빼기 · 바꿔 끼기는 전투 밖이면 어디서든(지도의 「장비」 · 캠프 · 상점) 한다. 가방의 장비는 사는 값의 40%(rules.js EQUIP_SELL)에 판다 — 두 번 눌러야 팔린다.
값 · 드랍 확률 · 등급은 기획서에 없어 우리가 정했다(`js/rules.js`).
