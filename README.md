## 지금 되는 것 (프로토타입)

- 사도 135명 중 셋을 편성한다. 위치(전열·중열·후열)는 사도마다 정해져 있고 바꿀 수 없다
- 턴제 카드 전투 — **AP** 파티 공용 매 턴 3(남으면 사라짐), 매 턴 5장 뽑기, 줄을 따지는 카드
- **고학년 스킬** — 인게임 고학년 스킬. 덱 밖에 있고, 카드에 AP를 쓸 때마다 차는 **고학년 게이지**(0~300%)로 쓴다
- **성격 상성** — 원작의 속성. 광기 → 순수 → 냉정 → 광기, 활발 ↔ 우울. 유리하면 주는 피해 +10%
- **관계** — 함께 나온 이야기가 많은 사도끼리는 호칭 연계가 터지고, 각별한 짝이 있으면 첫 턴 AP +1
- **신탁** — 고유 카드마다 다섯(강화·경량·연계·변형·각성). 전투 보상 때 가끔 떠서 하나를 붙인다
- **겨우살이의 축복(신뜩임)** — 고유 카드마다 그 카드만의 한 줄(✦). 신탁이 뜰 때 드물게 같이 붙어, 고른 신탁 위에 얹힌다. 배율 · 덤 효과 · 코스트 -1 · 보존(그 카드가 손에 남는다)([docs/14-사도리뉴얼v3.md](docs/14-사도리뉴얼v3.md))
- 3층 — **에르피엔**(요정 왕국) → **모나티엄**(엘프 도시) → **벨리티엔**(마녀 왕국·세계수 뿌리).
  층마다 지도 12칸과 보스. 3층 보스를 넘으면 캠프 한 번 뒤 **세계수 뿌리 깊은 곳**에서 마지막 싸움 — 그것을 이겨야 판을 깬다.
  처음 고른 셋으로 끝까지 간다(층 사이 교체 없음)
- 적은 게임에서 꺼낸 **실제 몬스터**이고, **원작에서 그 땅에 사는 것만** 나옵니다(도감의 교주의 기록 — [docs/11-적.md](docs/11-적.md)) — 보스 넷까지 47종.
  에르피엔은 저혈당·고혈당 요정·불효자손·산사모·목매킴·부스러기·멜로 셋·루파루·누루링-요정, 엘리트 새마음금고.
  모나티엄은 엘프 돌격병·엘프 명사수(노동반·의장대·호위)·드론 S형·G형·누루링-엘프·한입초, 엘리트 드론 G형 · 시설 경비.
  벨리티엔은 누루링-마녀·누루링 인형·햇팽이. 적마다 낱말 한두 개(방패·저격·치유사·폭탄·가시·재생·차지꾼…)로 공략이 읽힙니다. 보스는 커버러스·M.E.O.W·햇팽이 마녀(마녀의 의식이 옮겨진 햇팽이 — 원작에 마녀 왕국 보스가 없어 키웠다), 그리고 판의 마지막 우로스(엘리아스 프론티어 보스).
  적의 그림 한 장(나오는 적 · 적 정보)은 싸움터에서 입는 스킨과 같은 것만 쓴다

- **캠프** — 층마다 둘. 가운데는 캠프만, 보스 앞은 캠프 + 골디의 상점. 쉬기(HP +30% · 주말농장에 간 사도는 30% 로 돌아온다)와 수련(신탁) 중 하나
- **주말농장** — HP 가 0 이 된 사도는 쓰러진 채로 다음 싸움에 들고, 그 사도의 카드는 그 싸움의 덱에서 빠진다(싸움 중에 쓰러지면 손에 있던 그 카드만큼 새로 뽑는다). 돌아오는 길은 둘 — 캠프에서 쉬면 최대 HP 의 30%, 보스를 이기면 20%
- **골디의 상점** — 보스 앞 캠프에서. 중립 카드·고유 카드를 골드로 사고 카드를 뺀다. 골디는 할인하지 않는다([docs/09-상점.md](docs/09-상점.md))

- **장비** — 사도당 무기·방어구·장신구. 스탯 줄과 애착 Lv.3 스탯이 돈다. 보스 보상·골디의 상점에서 얻고 전투 밖이면 어디서든 낀다. **한 번 끼면 빼지 못하고**, 찬 칸에 새 장비를 끼면 낀 것은 사는 값의 40% 에 팔린다(묻고 나서). 장비는 어디서든 누르면 스탯 · 효과 · 애착 · 파는 값을 자세히 본다

아직 없는 것: 장비 **효과 줄·애착 카드 강화**, **기적**, 중립 카드 43장 중 33장(효과 규칙이 모자라 진열하지 않음).

규칙의 원본은 기획서이고, 왜 그렇게 했는지와 걷어 낸 옛 설정(SP·본색·스트레스·성격 시너지·유물)은
[docs/01-규칙.md](docs/01-규칙.md) 에 적어 두었습니다.

### 카드는 원작 스킬에서 나옵니다

사도의 포지션·공격 타입·실제 스킬은 나무위키의 트릭컬 리바이브 문서에서 가져옵니다.
프리클은 탱커가 아니라 **가시 촉수 소환사**이고, 마요의 독은 지속 피해가 아니라
**공격력을 깎는 중독**이며, 에르핀은 **후열 마법 딜러**입니다.

**수치만 우리 것입니다.** 원작 계수(엘레나 저학년 585%)는 9명 실시간 자동 전투의 비율이라
3명 턴제 카드 게임에서는 뜻이 없습니다. *무엇을 하는가는 원작, 얼마나 세게는 우리 자* —
자세한 것은 [docs/01-규칙.md](docs/01-규칙.md).

## 기획서가 원본입니다

저장소 맨 위의 기획서(`트릭컬_기획서_전체.md`)를 파서로 읽어 게임 데이터로 만듭니다. **손으로 옮기지 않습니다** —
기획서를 고치고 다시 돌리면 됩니다.

```
npm run design        기획서 → js/data/design.js   사도 135 · 카드 1,080 · 신탁 2,700
npm run design:check  원문과 대조
npm run build         → js/data/built.js           효과까지 붙인 카드
npm run effects       산문을 몇 % 읽었나            89.9%
npm run fx            실행기가 기획서대로 도는가
```

효과는 산문입니다 — `"무작위 적 4회 × 공격력 50% 피해"`. [js/effects.js](js/effects.js) 가 그걸 읽고
[js/run-fx.js](js/run-fx.js) 가 실행합니다. 수치는 전부 **스탯 기반 %** 입니다:

```
특대 마력탄  공격력 15 × 220% = 33 피해
도끼도 튕기는 몸  방어력 2 × 200% = 4 방어
토닥…            회복력 18(공격력 6 + 서포터 12) × 70% = 13 회복
```

회복은 공격력이 아니라 **회복력** 으로 셉니다 — 회복력 = 공격력 + 역할 몫(서포터 +12 · 탱커 +7 · 딜러 0).
공격력이 낮은 서포터·탱커도 치료가 너무 작아지지 않게 받치는 바닥이고, 딜러는 전과 같습니다.
회복이 하는 일인 장비(간호복 · 램프 · 펜던트 …)에는 스탯 줄 「회복력 +N」 이 붙어 회복력에만 더해지고, 「회복력 +N%」 증감(교주 카드 「효율적인 회복」 따위)은 곱해집니다.

**못 읽은 것은 지우지 않고 셉니다.** 효과 조각 1,451개 중 1,295개(89.2%)가 실제로 돌고,
나머지는 `pendingFx`(규칙은 읽었는데 몸이 아직 없는 것)와 `unknownFx`(모르는 것)에 쌓입니다.
카드가 아무 일도 안 하면서 멀쩡해 보이는 게 가장 나쁩니다.

## 팀 편성

큰 세로 카드 셋을 가운데 세우고, 오른쪽에 이번 싸움을 적습니다.
트릭컬 쪽을 얹었습니다 — 카드마다 **위치**(전열·중열·후열)를 고릅니다.

- 카드에 스탠딩 일러스트, 왼쪽 위에 **역할·성격·종족** 뱃지, 오른쪽 위에 **⌕**(사도 정보),
  아래에 이름·종족·피해속성과 **★성급**
- 위치는 **고르는 것이 아니라 정해진 것**입니다. 셋 중 제 자리에 불이 들어오고
  「후열 딜러 · 적은 전열부터 노린다」고 적어 줍니다
- 빈 자리를 누르면 아래에서 **서랍**이 올라오고, 135명에서 골라 넣습니다
- 오른쪽: **이번에 나오는 적** · 이 층을 지나려면 · **덱 열두 장**
- 그 아래 한 줄: 사이(각별/친함 · N편) · 성격 상성 · **첫 턴 AP**(매 턴 3, 사이가 좋으면 +1)

훑어보기는 「사도 도감 ↗」으로 넘어갑니다.

## 도감

**도감** — 왼쪽에 **종족** 여덟, 가운데 초상 격자, 위에 거르개와 정렬. 편성에서 「사도 도감 ↗」으로 넘어갑니다.

- **135명을 한자리에** 깝니다. 이격(에르핀(왕도) 같은 괄호 붙은 열아홉)도 섞어 두고 표만 답니다.
  탭으로 갈라 놓았더니 「에르핀」을 찾아도 에르핀(왕도)가 안 나와서, 찾는 쪽에서는
  그 사도가 아예 없는 것으로 보였습니다
- 카드마다 왼쪽 위에 **역할·성격** 뱃지
- 거르개는 성격 여섯 · 역할 셋, 정렬은 성급 · 이름 · 공격 · 체력

**사도 정보** — 왼쪽 갈피 넷(**능력치 · 카드 · 신탁 · 고학년 스킬**), 오른쪽에 내용.
들어가면 **능력치**부터 뜹니다.

카드 갈피가 이 화면의 핵심입니다. **시작 카드 넉 장 + 고유 카드 넉 장**을 실제 카드 꼴로
세워 그리고, 오른쪽에 **고학년 스킬**를 육각 틀로 둡니다. 덱빌더에서 사람을 고르는 일은 곧
카드를 고르는 일이라, 고르기 전에 여덟 장을 다 보여 줍니다.

### 카드 그림은 우리가 그립니다

사도 135명 × 여덟 장(시작 넷 · 고유 넷) = **1,080장**을 그립니다.

**고학년 스킬은 안 그립니다.** 인게임 고학년 스킬이고 그 아이콘이 곧 고학년 스킬 표라,
원작 `icon_graduateskill_*` 을 그대로 씁니다.

나머지 458자리에는 꺼내 둔 원작 스킬 아이콘이 임시로 박혀 있습니다. **우리 것이 아니라**
자리가 비어 보이지 않게 메워 둔 것이고, 그린 것이 들어오면 자동으로 물러납니다.

```
npm run bible                 나무위키 인물 사전 → js/data/bible.js (133/135명)
npm run brief -- --todo       몇 자리 남았나
npm run brief -- 에르핀        그 사도에게 필요한 것 전부 — 참고 그림 · 카드 아홉 장 · 낼 곳
npm run shrink                1024×1536 PNG → 512×768 WebP (장당 2.7MB → 144KB)
npm run cardart               assets/cardart/ 를 훑어 js/data/cardart.js 로
```

줄이는 걸 건너뛰면 1,215장이 **3.1GB** 가 됩니다. 카드는 화면에서 152px 로 뜹니다.

`brief` 는 참고 그림과 카드 글 말고 **인물 사전**도 함께 펼칩니다 — 어떤 사람인가 ·
확정 설정 · 버릇과 성미 · 말버릇 · 감정 · 상황별 표정 · 하지 않는 것. 장면이 안 떠오를 때
버릇을 읽으면 대개 거기 있습니다(에르핀의 「하루 열두 끼」가 곧 「친구 몰래 케이크」입니다).

사전은 [사도 데스크](https://github.com/RED9839/sado-desk)의 `bible.json` 에서 가져옵니다.
나무위키 트릭컬 리바이브 사도 문서를 읽고 요약·재구성한 것으로 **CC BY-NC-SA 2.0 KR**
(저작자표시 · 비영리 · 동일조건변경허락)을 따릅니다. 원문을 옮긴 것이 아닙니다.
말투·관계·극장 줄거리는 안 가져옵니다 — 글 쓸 때 쓰는 것이지 그림에 쓰는 것이 아닙니다.

### 도감의 작은 표는 원작 아이콘입니다

성격 여섯 · 역할 셋 · 위치 셋 · 종족 여덟. 낱장이 아니라 묶음 아틀라스
(`atlases/commonicons` — 2048×2048 한 장에 402개)에 눌려 있어서, 이름표를 읽고 잘라냅니다.

```
npm run uiicons
```

잘못 잘리면 색부터 틀어집니다. 그래서 도구가 성격 여섯 빛깔을 원작과 견주어 **스스로 봅니다** —
순수는 초록, 광기는 빨강, 냉정은 하늘, 우울은 보라, 활발은 노랑. 하나라도 어긋나면 멈춥니다.

꺼낸 것이 없으면 화면은 글자 한 자로 떨어집니다. 그래서 `npm run shot` 이 따로 있습니다 —
가짜 DOM은 "글자로 떨어진 것"과 "아이콘이 뜬 것"을 구별하지 못합니다. 실제로
문서에 안 붙은 `<img>` 에 `loading="lazy"` 를 걸어 둔 탓에 아이콘이 **한 장도 안 뜬 채로**
smoke 검사 백 몇 개가 전부 통과한 적이 있습니다. `shot` 은 진짜 크롬으로 띄워
카드 116장의 역할·성격 아이콘이 데이터와 맞는지, 그림이 0×0 이 아닌지까지 봅니다.

그리는 법은 [docs/05-카드일러스트.md](docs/05-카드일러스트.md) 에 있습니다 —
참고 그림 차례, 카드 글에서 장면 뽑는 법, 언제나 붙이는 말, 세계 규칙, 내기 전 여섯 줄 검사.

### 얼개는 빌려 오고 낱말은 안 빌려 옵니다

한동안 도감 머리에 「모든 세력」이라고 적혀 있었습니다. 트릭컬에 세력이라는 구분은 없습니다.
세력 → **종족**, 열 → **위치**, 등급 → **성급**, 상세 정보 → **사도 정보** 로 맞췄고,
쓰는 말을 [docs/06-낱말.md](docs/06-낱말.md) 에 적어 뒀습니다. `npm run smoke` 가
빌려 온 말이 도로 끼어들지 않았는지 화면 글자를 훑습니다.

### 아는 낱말에는 밑줄이 그어집니다

카드 글의 **동상 · 간식 · 취약 · AP** 같은 낱말에 점선 밑줄이 그어집니다.
짚으면 풀이가 뜨고, 누르면 쪽지가 뜹니다 — 손가락으로도 봐야 하니까요.

```
동상  전용
적 스택. 턴 시작 시 스택당 공격력 20% 피해,
스택 3 이상이면 약화. 공격 받을 때마다 1 감소.
```

풀이는 세 군데에서 옵니다.

| 갈래 | 몇 개 | 어디서 |
|---|---|---|
| 사도 전용 | 135 + 곁말 13 | 기획서의 사도별 키워드 |
| 상태 | 8 | 기획서 「전투 규칙」 줄을 **파서로 읽습니다**(손으로 옮기면 어긋납니다) |
| 규칙 | 6 | AP · 드로우 · 치명 · 신탁 · 기적 · 고학년 게이지 |

**풀이가 없는 낱말 다섯**(개전 · 종극 · 주도 · 보존 · 소멸)은 기획서에 이름만 있습니다.
그럴듯한 풀이를 지어 넣으면 규칙이 조용히 생겨 버리니 **비워 두고 그렇다고 적습니다.**
밑줄도 흐리게 긋고, 누르면 "기획서에 이름만 있고 풀이가 아직 없습니다"라고 말합니다.

**한 칸에 두 가지가 적힌 사도**가 있습니다. 그윈의 키워드는 「깃발」인데 풀이 안에
「동상」이 또 들어 있어서, 깃발을 누르면 동상 풀이까지 같이 떴습니다. 문장 첫머리에 선
「」만 **곁말**로 떼어 제 풀이를 줍니다 — 이제 깃발은 깃발만, 동상은 동상만 뜹니다.

떼는 자리를 잘못 잡으면 풀이가 중간에 끊깁니다(아멜리아 것이 「…받을 때마다」에서
끊겼습니다). 눈으로는 멀쩡해 보여서 **숫자를 세어** 확인합니다.

### 카드를 누르면 펼쳐집니다

카드 글 한 줄에 **하는 일**과 **낱말 풀이**가 뒤섞여 있는 것이 있습니다.
그윈의 스노우포그가 그렇습니다 — 한 줄로 읽으면 무엇이 하는 일이고 무엇이 안개의 뜻인지
갈라지지 않습니다. 카드를 누르면 이렇게 펼칩니다.

```
① 스노우포그   스킬
2턴간 안개

안개   적 전체 매 턴 피해 50%·동상 1, 적이 주는 피해 -5%. 동상 3 이상 적은 기절
동상   스택형 둔화(스택당 그 적이 주는 피해 -3%, 최대 3스택), 3스택 이상 적은 스노우포그에 기절.
기절   그 턴에 아무것도 못 한다. 그 사도의 카드도 못 쓴다.
```

**말을 지어내지 않습니다.** 기획서 글을 자르기만 합니다 — 「적 전체에 안개 부여」 같은
매끄러운 문장은 사람이 쓴 것이라, 도구가 흉내 내면 없던 뜻이 생깁니다.

글 안에 제 낱말을 품은 카드는 지금 **스노우포그 한 장**뿐입니다. 기획서가 늘리면
`npm run kwcheck` 의 숫자가 따라 오릅니다.

밑줄은 틀려도 멀쩡해 보입니다 — 「방어력」 안의 「방어」에 밑줄이 그어져도 글은 그대로입니다.
그래서 `npm run kwcheck` 이 걸리면 안 되는 자리를 예시로 박아 두고 1,080장을 훑습니다.

```
ok  방어력 200% 방어 → [방어]            앞의 '방어력' 은 건너뛴다
ok  공격력이 가장 높은 아군 → []
ok  고학년 게이지 300% → [고학년 게이지]   긴 낱말이 이긴다
ok  546/1080장에 밑줄이 붙는다 (51%) · 모두 804군데
ok  곁말 13개를 떼어도 풀이가 안 잘렸다
ok  펼쳐도 카드 글을 안 잃는다
ok  전용 키워드가 제 카드에 나오는 사도 117/135
```

## 보상 — 고유 카드와 신탁

이기면 **그 파티 사도의 고유 카드** 셋 중 하나를 덱에 넣습니다.
기획서가 그렇게 짜여 있습니다 — 사도당 시작 카드 넷은 처음부터, **고유 카드 넷은 판을 돌며**.
카드 위에 초상과 이름을 붙여 누구 것인지 바로 보이게 했습니다.

**신탁**은 조건이 둘입니다.

1. **이미 가진 고유 카드**에만 붙습니다. 없으면 「고유 카드를 먼저 얻으세요」
2. **무조건 일어나지 않습니다.** 기획서도 「신탁이 발생할 때」라고만 쓰고 확률값은 없어서,
   `FLASH_CHANCE = 0.35` 로 **우리가 정했습니다**(`js/rules.js`). 한 판에 보상이 열두 번이니
   네 번쯤 뜹니다. 안 뜨면 「이번에는 신탁이 일어나지 않았습니다」

뜨면 가진 고유 카드 하나를 골라 **다섯 중 무작위 셋**을 보여 줍니다. 한 카드에 하나만 붙습니다.
선택지마다 ①~⑤ 번호·종류·이름·바뀐 글을 보여 주고, 아래에 **「지금: …」** 으로 현재 효과를 같이 둡니다.

보상은 **들어올 때 한 번만 굴립니다** — 다시 그릴 때마다 굴리면 볼 때마다 카드가 바뀝니다.

> **아직 안 한 것** — 기획서에 기적 규칙이 있습니다.
> 「선택지 3개 중 1개가 낮은 확률(기본 5%)로 기적 선택지가 된다」.
> 값은 `SHIN_CHANCE` 로 적어 뒀지만 풀(공격·스킬·강화별 표)을 아직 파서로 안 읽어서 쓰지 않습니다.

## 전투

**싸움터**에 왼쪽은 아군, 오른쪽은 적이 서고, 가장자리에 **덱 더미와 버린 더미**가 놓입니다.
아군은 **전열이 앞, 후열이 뒤** — 줄이 곧 서는 자리라 깊이로 보입니다.
도감은 밝게, 전투는 어둡게 갈라 놓았습니다.

손패는 **도감 카드와 같은 꼴**입니다 — 그림이 카드를 채우고 코스트·이름·타입이 위에,
효과가 아래에. 아래 가는 띠가 누구 카드인지 알려 줍니다.
**사도 배치 순서**로 줄 섭니다(앞줄 사도의 카드가 왼쪽). **손에 든 것처럼 펼쳐지고**,
짚으면 그 장만 일어섭니다. 그린 일러스트가 없는 카드는 **그 사도의 인게임 그림**을 깝니다 —
무늬만 있는 것보다 낫고, 누구 카드인지도 같이 읽힙니다.

- **손에는 열 장까지.** 넘치게 뽑으면 그 카드는 **사라집니다**(덱으로 안 돌아갑니다 —
  돌아가면 손이 찬 채로 같은 카드를 무한히 다시 뽑는 고리가 생깁니다)
- **덱 더미와 버린 더미**를 눌러 무엇이 남았는지 봅니다. 같은 카드는 묶어서 셉니다.
  뽑을 더미는 **차례를 안 보여 줍니다** — 섞여 있으니까요
- 대상이 필요한 카드를 고르면 **「칠 적을 고릅니다」** 라고 말해 줍니다

- **카드를 고르거나 카드에 마우스를 올리면 적마다 얼마나 깎이는지 뜹니다** (-11 · 처치).
  체력 막대 끝에는 깎일 만큼 그림자가 집니다. 한 명을 치는 카드는 적마다 "이 적을 치면" 의 값을,
  적에 올리면 그 적을 쳤을 때 모두에게 들어가는 값을 보여 줍니다. 무작위 대상은 **최대**로 셉니다.
  계산식을 따로 베끼지 않고 **판을 복사해 실제로 내 봅니다** — 취약·상성·방어·실드·X 코스트가
  그대로 들어가서 실제와 어긋나지 않습니다(`tools/check-fx.js` 가 69번 내 보고 대조합니다). 치명타는 뺍니다
- 적 위에 **의도**가 붙습니다 (⚔ 12 · 4×3 · 🛡 웅크린다). 숫자는 힘·약화가 들어간 값입니다
- **적의 수가 다양합니다.** 전에는 모두 정해진 순서를 돌아서 두 판이면 외워졌습니다
  - 잡몹 일부는 **섞어서** 고릅니다 — 다만 같은 종류를 세 번 잇지 않습니다
  - **여러 번 치기**(4×3 — 방어가 먼저 벗겨집니다) · **적 전체 방어** · **적 회복** · **맞히면서 취약 걸기**
  - **힘 모으기** — "숨을 크게 들이쉰다 → 다음 턴 덮친다 26". 다음 턴에 반드시 옵니다.
    **봉인하거나 수를 흐트러뜨리면 흩어집니다**
  - **체력이 떨어지면 수가 바뀝니다** — 보스 셋은 절반, 먹보곰·방패 인형도. 보스는 더 세게가 아니라
    다르게 바뀝니다(한 바퀴 동안 들어오는 피해를 전과 비슷하게 맞췄습니다)
- **실드가 이제 피해를 받아 냅니다.** 전에는 방어만 깎이고 실드는 쌓이기만 했습니다
- 적이 쓰러진 뒤 **세 번째 적을 눌러도 두 번째 적이 맞던 것**을 고쳤습니다
- 고학년 게이지는 **파티 공용 0~300%** — 바에 **150·200·250·300% 눈금**을 새겨서
  어디까지 차야 누가 쓸 수 있는지 보입니다
- AP는 숫자 옆에 **눈금**이 켜집니다. 체력은 싸움터에 선 모습 아래에만 둡니다 —
  상태창에 또 두면 같은 숫자가 두 번 뜹니다
- 아군 상태창에 HP·방어·실드·버프/디버프와 **사도 전용 키워드**(간식 2 · 수은막 1)가 보입니다

## 스킬 구성 — 나무위키를 읽고 135명을 다시 썼습니다

사도마다 **패시브 · 키워드 · 고유 카드 4장(신탁 5개씩) · 고학년 스킬**를 나무위키의 원작 스킬
(저학년 → 시그니처, 고학년 → 고학년 스킬, 강화 평타·어사이드·애착 아티팩트 → 패시브와 키워드)과 설정을 읽고 다시 짰습니다.
사도 정보 화면의 **원작** 줄에 무엇을 어디로 가져왔는지 적혀 있습니다.

**전에는 패시브가 글로만 있었습니다.** 「간식 3개가 되면 AP +1」 이라고 쓰여 있는데 전투에서는 아무 일도 없었습니다.
이제 패시브·키워드는 정해진 문법으로 쓰고 `js/passive.js` 가 읽어 **실제로 돕니다** — 발동하면 그 사도 위에 이름이 뜹니다.

- 언제: 전투 시작 · 턴 시작/종료 · 카드를 낼 때마다 · 시그니처 카드를 내면 · 「에르핀의 공격 카드를 N장」(그 사도 것만) · 「파티가 이번 턴 N장째」(파티 전체) · 적을 처치하면 · 맞으면 · 방어나 실드를 얻으면 · 적이 즉시 행동하면 · HP 50% 이하가 되면 · 「X」가 N개가 되면 · 항상 …
- 장수를 누구 것으로 세는지 글에 밝힙니다 — 「에르핀의 …」 는 그 사도 것만, 「파티가 …」 는 누가 냈든. 정보 창 칩도 「에르핀 공격 1/3」 · 「파티 2장」.
- 「(턴당 N회)」 는 없습니다. AP · 드로우는 턴에 한 번 도는 언제(턴 시작 · N장째 · 「X」가 N개 …)에만 붙고, 패시브가 끝없이 돌지 않는지 `tools/check-passive.js` 가 거센 턴으로 잽니다.
- 키워드: 자기 주머니 / **적에게 거는 표식** / **아군에게 씌우는 것**, 최대치, 턴마다 줄기, 1개당 능력치·지속 피해·지속 회복, N개가 되면 터지기
- 능력치 증감(주는/받는 피해 · 공격력 · 방어력 · 치명)을 이번 턴 · N턴간 · 이번 전투 동안 걸 수 있고, 칩으로 보입니다
- 문법과 수치 기준: [docs/07-스킬구성.md](docs/07-스킬구성.md)

**같이 고친 것** — 다시 쓰다가 드러난, 원래 안 돌던 것들입니다.
- **고학년 스킬이 게이지만 먹고 아무 일도 안 했습니다** — 효과를 옛 실행기로 돌려서였습니다
- **신탁을 고르면 카드가 신탁 글로 통째로 바뀌는데** 신탁 글이 차이만 적혀 있어("② 경량: 보존") 효과가 사라졌습니다.
  이제 신탁 글은 바뀐 뒤의 전문입니다
- 기획서 카드에서 건 **기절·도발·침묵이 아무 일도 안 했고**, 「취약 2턴」 이 1턴만 갔습니다
- **무적이 적이 치기 전에 풀려** 아무것도 막지 못했습니다
- 「간식이 있으면」 같은 조건이 카드 **맨 앞**에 놓여 카드 전체를 막았습니다(글 차례대로 읽게 고쳤습니다)
- 한 카드에 「4회」 가 있으면 **모든 피해 조각이 4회**가 됐습니다
- 공용 키워드 셋에 뜻을 정했습니다: **보존**(턴이 끝나도 손에 남는다) · **소멸**(이 전투에서 사라진다) · **개전**(첫 손패에 든다).
  주도·종극은 여전히 풀이가 없어 아무도 쓰지 않습니다

**코스트 — 고유 카드가 너무 쌌습니다.** 72%가 1코, 14%가 0코, 3코는 없었고 평균 코스트(1.01)가 시작 카드보다 낮았습니다.
- **기본 0코는 없습니다.** 0코는 신탁 ② 경량(늘 코스트 -1)으로 얻는 보상입니다. AP 를 주는 카드는 0코가 되지 않고,
  0코 카드는 드로우 1까지 — 크면 소멸이 붙습니다(무한 고리 방지)
- 사도마다 2코 이상 한 장은 있고, **3코 한 방**이 어울리는 39명에게는 한 장씩(광역 폭격 · 버티는 벽 · 판을 뒤집는 서포트)
- 지금: 1코 398 · 2코 101 · 3코 39 · X 2 — 평균 1.34. 검사기(`check-hero.js`)가 이 규칙을 막습니다
- 보스는 기절한 다음 한 턴은 버팁니다 — 기절로 보스를 묶어 두던 사도(마카샤)가 혼자 97% 를 깼습니다

**신탁 — 고르면 나아야 합니다.** 신탁을 받는 게 오히려 손해인 것이 많았습니다(2,700개 가운데 손해 1,306 · 하나 마나 394 · 기본에 없던 소멸 45).

- 코스트 기준 값어치가 기본의 **1.15배 이상**(같은 코스트면 더 세게, 코스트를 내렸으면 덜 잃게)
- 코스트를 올린 신탁은 값어치 합이 **1.6배 이상** — 숫자가 커지거나 쓸 만한 효과가 붙는다
- **소멸**은 기본에 있었거나 2배 넘는 한 방에만, 코스트를 내린 신탁에는 안 붙이고, 카드당 하나까지

지금 손해 0 · 하나 마나 0 · 소멸 12. `check-hero.js` · `check-gear.js` 가 막고, `node tools/oracle-audit.js [--list]` 가 숫자를 셉니다.

## 사도가 말합니다

전투 중에 사도가 제 말투로 말합니다 — 전투를 시작할 때, 맞았을 때, 적을 쓰러뜨렸을 때,
이겼을 때, 주말농장에 갈 때.

대본은 [사도 데스크](https://github.com/RED9839/sado-desk)의 `self-talk.json` 에서 가져옵니다.
**우리가 쓴 글이고 게임 대사 원문이 아닙니다** — 그 파일 머리말에 그렇게 적혀 있습니다(v0.11.7 원칙).

```
npm run talk      # 사도 데스크 대본에서 골라 js/data/talk.js 로
```

그 대본은 바탕화면 마스코트용이라 **반응**은 있고 **행동**이 없습니다. 맞았을 때·쓰다듬·심심함은
그대로 쓰지만, 전투 시작·적 처치·승리는 애초에 없어서 직접 썼습니다.
(옛 본색용으로 써 둔 줄 `ego` 는 남아 있지만, 본색이 고학년 스킬로 바뀐 뒤로는 불리지 않습니다.)
말투는 `talk-ko.json` 의 프로필을 따릅니다 — 마요는 음슴체로 교주를 "수집품"이라 부르고,
네르는 존댓말에 "하아", 티그는 반말에 "크핫".

처음엔 규칙을 느슨하게 잡았다가 에르핀의 전투 시작 대사로 *"놀아 줄 사람이 없네… 심심해서
몸이 배배 꼬인다구"* 가 붙었습니다. **틀린 대사보다 없는 편이 낫습니다** — 지금은 맞는 줄이
없으면 아무 말도 하지 않습니다.

## 세계관도 지어내지 않습니다

트릭컬에는 정리된 세계 규칙이 있습니다 — 죽음이 없고(쓰러지면 **주말농장**에 갑니다),
지성체는 전부 여성이고, 눈이 내리지 않고, 지명이 정해져 있습니다.
[docs/03-세계관.md](docs/03-세계관.md) 에 추려 두었고, `npm run world` 가 카드 이름·설명·
층 이름·사도 소개·적의 의도까지 272줄을 훑어 어기는 줄을 짚습니다.

## 관계는 지어낸 것이 아닙니다

`js/data/relations.js` 는 [사도 데스크](https://github.com/RED9839/sado-desk)의 `relations.json` 에서 뽑아냅니다.
게임 음성 말뭉치를 세어 만든 **통계**(함께 등장한 편수)와 **호칭 낱말**만 가져오고, 대사 원문은 가져오지 않습니다.

| 함께 나온 편수 | 사이 | 연계 |
|---|---|---|
| 20편 이상 | 각별 | 뒤 카드 ×1.35, 첫 턴 AP +1(짝이 여럿이어도 하나까지) |
| 8~19편 | 친함 | ×1.2 |
| 1~7편 | 안면 | +2 |
| 0편 | 초면 | 연계 없음 |

에르핀–네르 51편, 엘레나–아멜리아 30편, 에르핀–에슈르 24편.
연계가 터지면 실제로 쓰는 호칭이 뜹니다 — 네르가 에르핀을 부를 때 "여왕님!", 아멜리아가 엘레나에게 "시장님!".

데이터를 다시 뽑으려면:

```
npm run data      # 사도 데스크 data/ 에서 다시 만든다
```

## 그림 — 자리마다 다릅니다

원작이 자리마다 다른 그림을 쓰니, 여기도 그렇게 합니다. [js/art.js](js/art.js) 가 정합니다.

| 자리 | 쓰는 그림 | 어떻게 |
|---|---|---|
| **전투** | 인게임 사도 SD | 스파인 (움직임) |
| **이벤트·상점** | 스탠딩 일러스트 | 스파인 (움직임) |
| **맵 이동·교체** | 미니미 | 스파인, 또는 아틀라스에서 잘라낸 그림 |

셋 다 부품 단위 스파인이라(에르핀 스탠딩만 163개) 런타임이 있어야 움직입니다.
사도 데스크와 같은 방식입니다 — `.skel`+`.atlas` 를 그대로 두고 spine-webgl 4.1 이 굴립니다.

```
npm run spine        # 편성 여덟 + 미니미만 골라 assets/spine/ 으로 (1.8GB → 29.6MB)
npm run spine:check  # 정리한 것이 실제로 읽히는지
npm run minimi       # 미니미는 런타임 없이 잘라 쓸 수도 있습니다
```

**그림이 없으면 한 단계씩 떨어집니다** — 스파인 → 그림 한 장 → SD → 색과 이름.
런타임이 없어도, 아무것도 안 꺼내 뒀어도 게임은 돕니다.

> **런타임 라이선스.** Spine Runtimes 는 **쓰는 사람이 각자 Spine Editor 라이선스를 가져야** 합니다.
> 웹 공개판은 이 조건을 알고서 스파인을 그대로 싣기로 했습니다(라이선스 원문 `vendor/spine-webgl.LICENSE` 를 함께 올림).
> 권리자가 문제 삼으면 스파인을 끄고 그림 한 장으로 돌린 판으로 바꿉니다. 자세한 것은 [docs/04-스파인.md](docs/04-스파인.md).
