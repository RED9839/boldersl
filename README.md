# 볼제나 — 볼 제로 나이트메어

트릭컬 리바이브의 사도들로 하는 **로그라이크 덱빌딩 게임**입니다. 덱빌딩 게임들(카오스 제로 나이트메어 등)에서
영감을 받아 만들었고, 브라우저에서 돕니다.

**웹에서 해 보기 — https://bolzena.pages.dev** (비영리 공개판, 설치 없음)

> **비공식 · 비영리 팬 게임입니다.** EPID Games 및 트릭컬 리바이브 공식과 아무 관계가 없고, 어떤 승인도 받지 않았습니다.
> 전투의 얼개는 덱빌딩 로그라이크에서 영감을 받은 것일 뿐, Smilegate 와도 아무 관계가 없습니다.

## 어떻게 노나요

1. **편성** — 사도 135명 가운데 셋을 골라 파티를 짭니다. 위치(전열 · 중열 · 후열)는 사도마다 정해져 있습니다.
2. **지도** — 층마다 갈림길이 난 지도를 골라 갑니다. 칸은 일반 싸움 · 엘리트 · 이벤트 · 캠프 · 캠프(골디의 상점), 그리고 층 끝의 보스.
3. **전투** — 카드로 싸웁니다. 이기면 그 파티 사도의 고유 카드를 하나 덱에 넣고, 가끔 **신탁**이 떠 가진 카드를 바꿉니다.
4. **캠프 · 상점** — 쉬거나(파티 HP 회복) 수련(신탁)하고, 상점에서는 골드로 카드 · 장비를 사거나 카드를 뺍니다.
5. 세 층 — **에르피엔**(요정 왕국) → **모나티엄**(엘프 도시) → **벨리티엔**(마녀 왕국) — 을 지나
   마지막 싸움까지 이기면 판을 깹니다. 처음 고른 셋으로 끝까지 갑니다.

### 전투 화면

| 자리 | 무엇 |
|---|---|
| 오른쪽 적 위 | 적의 **행동 예고** 판 — 다음에 무엇을 할지, 숫자까지 |
| 왼쪽 위 | **파티 HP**와 방어 · 실드 · 파티 상태 |
| 왼쪽 아래 | 사도 칸과 **고학년 게이지** |
| 아래 한 줄 | 덱 더미 · 버린 더미 · **AP** · 턴 넘기기 |

카드를 고르거나 마우스를 올리면 적마다 얼마나 깎이는지 미리 보입니다. 밑줄 그어진 낱말을 짚으면 풀이가 뜹니다.

## 전투 규칙

| 규칙 | 내용 |
|---|---|
| **파티 HP 하나** | 세 사도의 HP 를 더한 하나를 셋이 함께 씁니다. 방어 · 실드도 파티에 하나. 사도는 쓰러지지 않고, 파티 HP 가 0 이 되면 판이 끝납니다 |
| **AP** | 파티 공용, 매 턴 3. 남으면 사라집니다. 손에는 열 장까지 |
| **카드 종류** | 공격 · 스킬 · 강화 |
| **강화 카드** | 사도마다 한 장(유일). 쓰면 그 전투에서 사라지고, 효과는 그 전투 끝까지 갑니다. 다음 전투에서 다시 씁니다 |
| **상태** | 파티에 거는 공용 버프는 대상 말 없이 겹으로 셉니다(「사기 1」 · 「불굴 2」). 한 사도에게만 세지는 것은 「전투 내내 자신 공격력 +15%」 같은 % 증감입니다 |
| **실드 · 회복** | 방어력 기준입니다(회복력이라는 능력치는 없습니다) |
| **강인도 · 격파** | 적마다 칸이 있습니다(보통 4 · 엘리트 5 · 보스 6). 카드의 타격 한 번마다 0.5칸, 약점 성격이면 1칸이 깎입니다. 0칸이면 **격파** — 파티 AP +1, 그 적은 다음 차례에 행동하지 못합니다. 적을 처치해서는 AP 가 오르지 않습니다 |
| **성격 상성** | 광기 → 순수 → 냉정 → 광기, 활발 ↔ 우울. **공명**은 어느 상성에서나 유리합니다(늘 약점 공격) |
| **고학년 스킬** | 덱 밖에 있는 사도의 큰 기술. 카드에 AP 를 쓸 때마다 차는 파티 공용 고학년 게이지로 씁니다 |

자세한 기준은 [docs/16-카제나전투.md](docs/16-카제나전투.md) · [docs/18-v6작성안내.md](docs/18-v6작성안내.md) · [js/rules.js](js/rules.js) 에 있습니다.

## 들어 있는 것

| 무엇 | 수 | 덧말 |
|---|---|---|
| 사도 | 135명 | 사도마다 전용 키워드 · 패시브 · 시작 카드 넷 · 고유 카드 넷 · 고학년 스킬 · 신탁 · 겨우살이의 축복 |
| 장비 | 87종 | 사도당 무기 · 방어구 · 장신구 |
| 교주 카드 | 43장 | 특정 사도에 묶이지 않는 공용 카드 |
| 적 | 49종 | 원작에서 그 땅에 사는 몬스터만 나옵니다. 보스 포함 |
| 이벤트 | 56종 | 층마다 그 땅의 사건. 파티에 그 사도가 있으면 열리는 선택지도 있습니다 |

- **신탁** — 고유 카드마다 다섯 갈래(강화 · 경량 · 연계 · 변형 · 각성). 보상 때 가끔 떠서 하나를 붙입니다.
- **겨우살이의 축복** — 카드마다 그 카드만의 한 줄. 신탁이 뜰 때 드물게 함께 얹힙니다.
- **관계** — 원작에서 함께 나온 이야기가 많은 사도끼리는 호칭 연계가 터집니다.
- **사도의 말** — 전투 중에 사도가 제 말투로 한마디씩 합니다.
- **세계관** — 트릭컬의 세계 규칙(죽음이 없고, 지친 파티는 돌아가 쉰다 등)을 어기지 않게 씁니다([docs/03-세계관.md](docs/03-세계관.md)).

카드의 **무엇을 하는가**는 원작 스킬에서, **얼마나 세게**는 이 게임의 기준에서 나옵니다.
원작 수치는 실시간 자동 전투의 비율이라 턴제 카드 게임에서는 뜻이 없어서입니다.

## 저작권과 출처

> **공개판에는 원작에서 꺼낸 그림(스파인 · 아이콘 · 배경)과 편성 대사가 들어 있습니다.**
> 저작권은 EPID Games 에 있고, **권리자의 요청이 있으면 즉시 내립니다.** 후원 · 광고 등 수익은 받지 않습니다.

- **원작 파일은 이 저장소에 넣지 않습니다.** `assets/`(꺼낸 그림 · 소리)와 `dist/`(공개판 빌드)는 `.gitignore` 이고,
  공개판은 따로 지은 `dist/` 를 Cloudflare Pages 에 올린 것입니다.
- 원작 파일을 꺼낼 때는 기기에 이미 받아 둔 리소스를 읽기만 합니다. 암호화된 표(게임 수치 · 대사)는 **보호를 풀지 않습니다** — 수치가 필요하면 직접 정합니다.
- **스파인 런타임** — Spine Runtimes 는 쓰는 사람이 각자 Spine Editor 라이선스를 가져야 합니다.
  공개판은 이 조건을 알고서 스파인을 그대로 실었고, 라이선스 원문(`vendor/spine-webgl.LICENSE`)을 함께 올립니다.
  권리자가 문제 삼으면 스파인을 끄고 그림 한 장으로 돌린 판으로 바꿉니다([docs/04-스파인.md](docs/04-스파인.md)).
- **인물 사전** — [사도 데스크](https://github.com/RED9839/sado-desk)의 `bible.json` 에서 가져옵니다. 나무위키 트릭컬 리바이브 사도 문서를
  읽고 요약 · 재구성한 것으로 **CC BY-NC-SA 2.0 KR**(저작자표시 · 비영리 · 동일조건변경허락)을 따릅니다. 원문을 옮긴 것이 아닙니다.
- **전투 대사** — 사도 데스크의 `self-talk.json` 에서 가져옵니다. **우리가 쓴 글이고 게임 대사 원문이 아닙니다.**
  전투 시작 · 적 처치 · 승리처럼 그 대본에 없는 줄은 직접 썼습니다.
- **관계** — 사도 데스크의 `relations.json` 에서 함께 등장한 편수(통계)와 호칭 낱말만 가져옵니다. 대사 원문은 가져오지 않습니다.

## 개발자용

빌드 단계 없이 `index.html` + ES 모듈로 돕니다.

```
npm run serve     # http://127.0.0.1:8765
```

**저장소만 받아서는 그림이 나오지 않습니다.** 게임 그림은 올리지 않기 때문입니다(`assets/` 가 비어 있음).
그림이 없으면 화면은 스파인 → 그림 한 장 → 색과 이름 순으로 떨어지고, 게임 자체는 그대로 돕니다.
그림까지 보려면 공개판에서 하거나, 각자 기기에서 꺼내야 합니다([docs/02-꺼낼수있는것.md](docs/02-꺼낼수있는것.md) · [docs/04-스파인.md](docs/04-스파인.md)).

### 데이터

규칙의 원본은 저장소 맨 위의 기획서(`트릭컬_기획서_전체.md`)입니다. 파서로 읽어 게임 데이터를 만들고, 손으로 옮기지 않습니다.

```
npm run design        기획서 → js/data/design.js
npm run design:check  원문과 대조
npm run build         → js/data/built.js (효과까지 붙인 카드)
```

### 검사

```
npm run smoke                  가짜 DOM으로 편성 → 전투 → 지도 → 상점 · 캠프 · 이벤트 → 끝 화면까지 눌러 본다
npm run shot                   진짜 브라우저로 띄워 사진을 찍고 데이터와 대조한다
npm run world                  세계 규칙을 어기는 글이 없는지 훑는다
node tools/check-hero.js --design   135명의 글이 전부 읽히는가 · 신탁이 기본보다 나은가
node tools/check-czn.js        작성 안내의 베껴 쓰는 줄이 다 읽히는가
node tools/check-toughness.js  강인도 · 격파
node tools/check-events.js     이벤트 선택지를 전부 실제로 골라 본다
node tools/run-sim.js --bot smart --parties 20 --runs 3 --jobs 2   난이도 — 사람만큼 하는 봇의 완주율
```

그 밖의 `tools/check-*.js` 도 저마다 한 갈래(장비 · 패시브 · 축복 · 저장 …)를 봅니다.
난이도 기준은 사람만큼 하는 봇이 한 판을 20~30% 완주하는 것입니다([docs/11-적.md](docs/11-적.md)).

### 공개판 올리기

```
npm run build:deploy   # dist/ 를 짓는다 — 코드 + 게임이 읽는 그림만 + 편성 대사
npm run deploy         # 짓고 Cloudflare Pages(bolzena)에 올린다 — 먼저 npx wrangler login
```

`assets/` 가 채워진 기기에서만 됩니다.

### 짜임새

```
index.html · css/style.css
js/
  main.js      화면 전환
  ui.js        그리기와 누르기
  combat.js    전투 규칙(화면을 모른다 — 시뮬레이터가 그대로 돌린다)
  run.js       한 판의 상태
  rules.js     전투 수치
  effects.js · run-fx.js · passive.js   카드 글 읽기 · 실행 · 패시브
  art.js · spine-view.js                그림 어댑터 · 스파인 그리기
  data/        기획서에서 만든 데이터 · 적 · 이벤트 · 관계 · 대사
tools/         데이터 만들기 · 검사 · 시뮬레이터 · 배포
docs/          설계 문서
```
